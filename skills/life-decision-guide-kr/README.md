# life-decision-guide-kr

《인생 가성비 가이드》 한국어판(book-kr/)으로 인생 결정 질문에 답하는 스킬.

## 설치

이 저장소의 `skills/life-decision-guide-kr/` 폴더를 다른 저장소나 글로벌 스킬 디렉토리로 복사하면 된다:

```bash
# opencode 전역 스킬
cp -r skills/life-decision-guide-kr ~/.config/opencode/skills/
```

로컬에 `book-kr/`이 없으면 원격 저장소(seolcoding/HowToLiveBetter-KR)를 얕은 클론해서 쓴다. SKILL.md 1단계에 명령이 있다.

## 전제

- 답변 품질은 `book-kr/`의 현지화 진행도에 따른다. 상태는 `book-kr/README.md` 표.
- 현지화 안 된 절은 중국어 원문(`book/`)으로 답하되, 답변에 "중국 기준" 표기를 남긴다.
- 절을 새로 현지화하려면 [../kr-localizer/SKILL.md](../kr-localizer/SKILL.md) 파이프라인을 쓴다.

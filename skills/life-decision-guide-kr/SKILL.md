# 인생 결정: 한국어판 책을 먼저 찾아보고 답하기

누군가 구체적인 인생 문제를 물으면 먼저 `book-kr/`에서 관련 항목을 찾고, 책의 계산 방식대로 정리해서 답한다.

**찾지 못했으면 답하지 않는다.** 답변의 모든 숫자와 법령, 결론은 본문 특정 항목으로 역추적이 가능해야 한다. 안 되면 "책에 없다"고 정직하게 말하고, 상식선에서 판단할 수는 있지만 그건 책의 내용이 아니라고 표기한다. 기억으로 숫자, DOI, 법 조항 번호를 채우지 않는다.

책은 얻으려는 것을 4가지로 나눈다: 수명, 시간과 에너지, 돈, 신체적 자유. **4가지를 따로 계산하고 서로 환산하지 않는다.** `총사망률 12% 감소`와 `연 50만 원 절약`은 같은 눈금 위에 있지 않다.

## 0단계: 즉시 중단할 건지 보기

- **진행 중인 응급상황**(쓰러졌는데 숨을 안 쉬는 경우, 큰 피, 화재, 익사, 감전, 중독, 뇌졸중·심근경색 증상): 먼저 **119**에 전화하고 현장 첫 동작부터 말한다. 원문 기준 §13. 비용 효율 논의는 그다음.
- **자살 생각, 살고 싶지 않은 경우**: 먼저 자살예방 상담전화 **109**를, 정신건강 위기면 정신건강복지센터 **1577-0199**를 안내한다. §1, §29 조항을 그다음에 언급한다. 동기 분석이나 설득은 하지 않는다.
- **진행 중인 법적 절차**(소환, 구금, 기소): 먼저 §8 해당 항목을 가리키고, 책은 일반 사례만 다루니 구체적인 케이스는 변호사를 찾아야 한다고 말한다.
- 가정폭력·스토킹: 여성긴급전화 **1366**(24시간), 위기 시 **112**. §8 가정폭력 관련 항목.
- 다른 경우는 아래 절차에 따른다.

## 1단계: 본문 가져오기

**로컬**: 현재 디렉토리 또는 상위 디렉토리에 `book-kr/README.md`가 있으면 로컬 모드. 바로 읽는다.

**어느 절이 이미 한국어로 현지화됐는지**: `book-kr/README.md`의 표를 확인한다. 상태가 ✅ 또는 🟨이면 그 절에서 찾는다.

**현지화 안 된 절일 때**: 원문 `book/`(중국어)에서 찾되, 답변 앞에 한 줄 표기를 남긴다: `이 절은 아직 한국어판이 없어요. 중국 원문 기준으로 답하니, 법·제도·전화번호는 한국 기준이 아니에요.` 그리고 중국 기준 내용(법조문, 기관, 전화번호)을 한국 사실처럼 말하지 않는다. 한국 대응을 꼭 알려줘야 하면 검색으로 1차 출처 확인 후 별도 표기하고, 확인 실패 시 "확인 필요"로 남긴다.

**원격**: 로컬에 없으면 얕은 클론 1회:

```bash
git clone --depth 1 https://github.com/seolcoding/HowToLiveBetter-KR.git "${TMPDIR:-/tmp}/life-os-kr"
```

## 2단계: 절 찾기

1~3개의 절을 고른다. `book-kr/README.md`의 표(절 번호, 한국어 제목, 원문 링크, 등급)로 사용자의 질문과 대응시킨다. 현지화 안 된 절은 원문 `book/` 파일을 연다.

장문은 `docs/`에 있다(한국어판이 아직 없으면 중국어 원문).

## 3단계: 항목 찾기

절 파일은 최대 110KB. 전체를 읽지 말고 키워드로 찾는다:

```bash
grep -rn '^### ' book-kr/ | grep -E '키워드1|키워드2'        # 항목 제목 목록
grep -rn -B2 -A8 '키워드' book-kr/08-법적-말썽에-휘말리지-않기.md   # 본문 검색(문맥 포함)
sed -n '/^### 16\. /,/^### 17\. /p' "book-kr/파일.md"          # 항목 번호로 전체 추출
```

**찾은 항목은 전체를 다 읽는다.** 적용 대상, 논쟁, 예외는 특히 `비고` 칸에 있다. 제목만 읽으면 조건을 놓친다.

한 항목의 형식:

```markdown
### 5. 집에서 쓰는 소금을 저염소금으로 바꾸세요
<!-- 成本标签: 钱=少 时间=少 毅力=否 收益=中 口径=死亡率 -->
- 비용: 한 봉지에 몇천 원 더 듦
- 쉽게: 요리할 때 이 소금을 쓰면 뇌졸중 확률이 약 14% 낮아져요
- 이득: 뇌졸중 14% 감소(HR 0.86), ...
- 근거등급: A
- 출처: Neal B, et al. (2021). NEJM. https://doi.org/10.1056/NEJMoa2105675
- 비고: 논쟁 있음. ...
```

`<!-- 成本标签 -->` 주석은 기계용 비용 태그다: 돈 0/적음/많음, 시간 적음/보통/많음, 의지 아니오/조금/예, 효과 큼/보통/작음, 기준 사망률/돈/시간/자유.

## 4단계: 정렬

책의 알고리즘대로. 느낌으로 하지 않는다:

1. 등급 공식은 원본 `index.html`이 기준. 기억하지 말고 직접 꺼내 본다:

   ```bash
   grep -n 'COST_W = \|e\.ratio = ' index.html
   ```

   앞줄은 세 가지 비용의 등급별 가중치(비용 점수 = 돈+시간+의지 합), 뒷줄은 효과 등급과 비용 점수의 `높음/중간/낮음` 매핑이다.
2. `index.html` 없이 본문만 있으면 등급을 매기지 말고, 효과 등급과 세 가지 비용 태그를 그대로 나열해 사용자가 스스로 판단하게 한다.
3. 비용 효율 기준으로 정렬, 같은 등급이면 근거 등급 A > B > C, 그다음 사용자 상황과의 관련성.
4. **다른 기준끼리는 정렬하지 않는다.** 돈을 버는 것과 수명을 버는 것은 따로 나열.
5. `낮음`은 하지 말라는 뜻이 아니다. 비용을 사용자가 스스로 판단해야 한다는 것뿐이다. 비용 효율은 저자의 판단이며 근거 등급과 별개다.

## 5단계: 답변 작성

1. **한 문장 결론**: 할 만한가, 안 하는 게 나은가, 첫걸음은 무엇인가.
2. **먼저 할 것**(3~7개, 위 순서대로). 항목당 1~3줄: 행동(동사로 시작), 뭘 들이고, 뭘 얻는지, 근거 등급, 출처 `§8 항목 17(차용증·보증)` 형식 — 괄호 안 단어는 항목 제목에서.
3. **하지 말 것 / 할 필요 없는 것**: 책에서 명확히 안 하거나 반대 근거가 있는 것은 별도로.
4. **책에 없는 것**: 정직하게 말하고 상식을 책 내용으로 위장하지 않는다.
5. 필요 시 재확인 시점 한 줄: 언제 다시 볼지, 어떤 신호가 보이면 방침을 바꿀지.

집어넣을 때 지킬 것:

- **수혜자 명시.** 책은 수혜자를 4등급으로 나눈다(본인 > 배우자·직계 > 친구·동료 > 타인). 타인 구조(모르는 사람 구조, 보증, 대리 이체)는 이점만 쓰지 말고 리스크도 같이 쓴다: 사기당함, 사건 휘말림, 보복.
- **"법이 나를 보호한다" 계열은 절차 비용까지 말한다.** 결과만 말하면 승소율을 이득으로 계산하는 것과 같다. 소송 여부, 소요 기간(1심 통상 수개월~1년 이상), 변호사 비용(승소 시 상대방 부담이 원칙이 아님)을 함께 말한다.
- **숫자는 항목 그대로, 한 글자도 수정하지 않는다.** 신뢰구간, 대상, 연도가 있으면 함께. HR/RR/OR 옆에 `약 28% 낮음` 병기, 원값 유지. 항목에 없는 숫자·증상·기전 해석 추가 금지.
- **말투**: 전문가 아닌 어른이 한 번에 이해할 수 있게. 전문 용어는 일상어로 즉석 풀이, 법 조항은 "어떤 결과를 겪고, 어떻게 해야 하는지"로. 출처 칸은 확인할 수 있도록 원본 그대로.
- **톤**: 담백하게, 설교 없이, 느낌표 없이. 사용자가 따르지 않는 것은 사용자의 일이고, 따라다니며 설득하지 않는다.
- **정책은 바뀐다**: §7, 15, 19, 24, 25, 31, 33의 금액·기한·목록에 작성 기준일이 있으니 답변에 날짜를 포함하고 공식 채널 재확인을 상기시킨다.
- `논쟁 있음` 항목은 반대 근거도 한 줄. `TODO 확인 필요` 항목은 결론으로 쓰지 않는다.
- 나무위키·블로그·카페 2차 요약 인용 금지. 항목 `출처` 칸의 링크만.

## 경계

이 책은 일반적인 기준이며 의사, 변호사, 회계사를 대체하지 않는다. 구체적인 질병, 사건, 세금은 해당 전문가에게. 개인 맞춤형 투자 조언은 하지 않는다.

책의 관점은 저자의 것이며, 비용 효율 정렬도 저자의 판단이다. 사용자가 항목에 동의하지 않으면 책 근거를 제시하는 것으로 충분하다. 논쟁하지 않는다.

# 한국 현지화 에이전트

`book/`(중국어 원본)의 절 하나를 골라 `book-kr/`의 대응 파일로 현지화한다. 결과물은 번역이 아니라 한국 독자용으로 다시 쓴 책이다.

## 먼저 읽을 것

1. [KR-GUIDE.md](../../KR-GUIDE.md) — 규칙 전부. 우선순위: KR-GUIDE > 이 문서.
2. [references/humanize-kr.md](references/humanize-kr.md) — 문체 규칙. 작성 단계에서 적용.
3. [references/kr-sources.md](references/kr-sources.md) — 1차 출처 목록과 치환표. 조사 단계에서 사용.

## 대상 절 정하기

- 사용자가 절 번호를 지정하면 그 절. 안 지정하면 `book-kr/README.md` 표에서 ⬜ 또는 🔁인 절을 고르고, 등급 🟢·🟡부터 진행한다.
- 작업을 시작하면 표의 상태를 곧 🟦로 바꾼다(커밋은 마지막에 한 번).

## 파이프라인

### 1. 원문 정독

- `book/NN-*.md` 전체를 읽는다. 큰 파일이면 항목(`### `) 단위로 나눠 읽는다.
- 해당 절의 `docs/核实记录/*`와 `docs/` 장문을 읽는다. 근거를 왜 골랐는지, 무엇을 배제했는지 거기 기록돼 있다. 이 기록은 한국어판에서도 유효하다.

### 2. 치환 설계

항목마다 분류한다:

- **의료 항목**: DOI·PubMed·HR/RR/OR 그대로 이식. 한국 지침·역학 자료가 있으면 출처에 보강.
- **법·제도 항목 (🔴)**: 한국 대응 조문·기관·제도를 조사해 새로 쓴다. 원문의 사고방식(비용 대비 결과, 과정 비용까지 말하기)은 유지.
- **불가 이식 항목**: 한국에 제도가 아예 다르거나 없으면(예: 户口, 公积金, 翻墙 규제), 뺀다. 남기는 게 독자에게 이득이면 "한국에는 없는 제도"라고 명시.

### 3. 적극적 조사 (검증 핵심)

웹 도구(webfetch, 검색)로 **1차 출처만** 확인한다:

- 법령 조문: 국가법령정보센터에서 조문 원문을 직접 연다. **조문 번호를 기억으로 쓰지 않는다.** 개정·시행일을 확인한다.
- 수치: KOSIS, 공단 공지, 부처 보도자료. 연도와 대상을 명시.
- 전화번호: kr-sources.md 치환표를 기준으로 삼되, 그 절에서 쓰는 번호는 공식 사이트에서 재확인한다. 확인 실패 시 번호를 빼고 기관명만 남긴다.
- 판례: 사건번호가 있는 공식 출처(종합법률정보, 법원·검찰 사이트)만.
- **나무위키·블로그·지식in·언론 단신은 출처가 아니다.** 힌트를 얻는 용도로만 쓰고, 실제 출처는 1차 자료로 갈아낀다.
- 못 찾은 것은 찾은 척하지 않는다: `TODO 확인 필요`를 남기고 다음 항목으로.

### 4. 작성

- 항목 형식은 KR-GUIDE.md의 예제 그대로. 비용태그 주석 줄은 원본 표기 유지.
- 문체는 humanize-kr.md. 해요체, 한 문장 한 정보, 번역테·AI腔 제거.
- 한국으로 갈아낸 항목의 비고에 확인일을 남긴다: `비고: 2026-10-05 법령 확인(국가법령정보센터)`.
- 근거등급 규칙(원본 CLAUDE.md 계승): A=수치 있는 1차 근거, B=근거 있으나 정량화 어려움, C=경험·통설. 논쟁 항목은 비고 맨 앞에 "논쟁 있음".

### 5. 자체 검증

KR-GUIDE.md의 체크리스트를 전부 실행한다. 특히:

```bash
# 중국 잔재 스캔 — 잡히는 줄은 전부 처리
grep -n '人民币\|医保\|社保\|公积金\|低保\|劳动仲裁\|淘宝\|微信\|12356\|12315\|12378\|96110\|120\|110' "book-kr/NN-파일.md"
```

- 전화번호 표와 대조. 법령마다 열어본 흔적(확인일)이 있는지.
- 문장: 50자 초과, 번역테, AI腔 샘플 검사.
- 의도치 않게 DOI를 바꾸지 않았는지 원본과 diff.

### 6. 마무리

- `book-kr/README.md` 표의 상태를 ✅로, 등급 칼럼은 그대로.
- 절 파일 맨 아래에 `## TODO 확인 필요` 목록.
- 리포트: 바꾼 항목 수, 갈아낸 제도 목록, 남은 TODO, 원본과 구조가 달라진 점.

## 금지

- `book/`, 원본 `README.md`, `docs/`(원본), `index.html`, `tools/` 수정 금지.
- 중국 수치·조문을 한국어로만 옮기는 것 금지.
- 출처 없는 한국 수치 쓰기 금지. "대체로 ~로 알려져 있다" 같은 완곡으로 근거 없는 주장 꾸리기 금지.
- 한 세션에서 절 여러 개를 뭉뚱그려 끝내려 하지 말 것: 절 1개 = 검증 1회 = 커밋 1개 권장.

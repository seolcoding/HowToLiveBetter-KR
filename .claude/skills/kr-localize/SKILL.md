# 한국 현지화 S1-S3 (분석·조사·초역)

`book/`(중국어 원본)의 절 하나를 한국 독자용으로 다시 쓴 **초역**까지 만든다. 문체 변환(S4)·윤문(S6)·항목별 개선(S7)은 뒤 단계가 한다. 이 스킬은 보통 `kr-localizer` 서브에이전트 안에서 돈다.

## 먼저 읽을 것

1. [KR-GUIDE.md](../../../KR-GUIDE.md) — 규칙 전부. 우선순위: KR-GUIDE > 이 문서.
2. [references/kr-sources.md](references/kr-sources.md) — 1차 출처 목록과 치환표.
3. [references/humanize-kr.md](references/humanize-kr.md) — 문체 규칙(초역에서는 문장 기계 기준과 번역테 백과만 적용).
4. 이미 끝난 절의 산출물 하나를 견본으로 본다: `kr-harness/chapters/14/`.

## 산출물 (전부 `kr-harness/chapters/NN/`, NN은 두 자리)

| 파일 | 내용 |
|---|---|
| `1-analysis.md` | 항목 인벤토리 표(#, 원문 제목 요지, 항목 등급 🔴/🟡/🟢, 처리 방침, 교체 대상) + 통계(항목 수, 근거등급 분포, DOI 보존 대상, 전화번호 치환, 삭제 후보, 교차 참조 조정) |
| `2-research.md` | 한국 대응 조사 기록. 법령마다 표(조문, 확인 내용, 확인 URL), 법령 머리에 법률 번호·개정일·시행일. 확인일 명시. 못 찾은 것은 **TODO** |
| `3-draft.md` | 초역 전문. 첫 줄 `[← 총목차](README.md)`, 빈 줄, `# N. 한국어 절 제목`, 절 도입부, 항목들, 맨 끝 `## TODO 확인 필요` |

## 절차

### S1 분석
- `book/NN-*.md` 전체를 읽는다. 크면 `### ` 단위로 나눠 읽는다.
- 해당 절의 `docs/核实记录/*`와 `docs/` 장문을 읽는다. 근거를 왜 골랐는지, 무엇을 배제했는지 거기 있다.
- 항목마다 등급과 처리 방침을 정해 `1-analysis.md`에 쓴다.

### S2 조사 (검증 핵심)
웹 도구(WebFetch, WebSearch)로 **1차 출처만** 확인한다.
- 법령 조문: 국가법령정보센터 원문을 직접 연다. **조문 번호를 기억으로 쓰지 않는다.** 개정·시행일을 확인한다. 조문 본문은 `lsBdyPrint.do`(인쇄 화면)가 잘 열린다. '제N조의2' 같은 가지 조문은 인쇄 화면에 본문이 안 나올 수 있다. 그때는 교차 참조로 확인하거나 TODO.
- 수치: KOSIS, 공단 공지, 부처 보도자료. 연도와 대상을 명시.
- 전화번호: kr-sources.md 치환표 기준, 쓰는 번호는 공식 사이트에서 재확인. 실패하면 번호를 빼고 기관명만.
- 판례: 사건번호가 있는 공식 출처(종합법률정보, 법원 사이트)만.
- 나무위키·블로그·지식in·언론 단신은 출처가 아니다. 힌트로만 쓴다. 언론 보도는 원본 CLAUDE.md의 「一手媒体报道」 5조건을 모두 만족할 때만.
- 못 찾은 것은 찾은 척하지 않는다: `TODO 확인 필요`.

#### 네트워크 요령 (2026-10-10 클라우드 VM 실측)
- law.go.kr은 연결이 자주 끊긴다(curl 8번 중 5번 성공). 한두 번 실패는 막힌 것이 아니다. `curl -sS --retry 5 --retry-all-errors --retry-delay 2 -m 30 <URL>`로 다시 시도한다.
- `https://www.law.go.kr/법령/…` 한글 주소는 자바스크립트 화면이라 본문이 안 나온다. `LSW/lsInfoP.do?lsiSeq=…`, `LSW/lsInfoR.do?…`, `LSW/lsBdyPrint.do?…`, 조문 단위 `LSW/lsSideInfoP.do?…&joNo=…`를 쓴다. lsiSeq는 WebSearch나 law.go.kr 검색 결과에서 얻는다.
- nhis.or.kr, moel.go.kr 같은 기관 사이트는 curl이 거의 실패하고 WebFetch로는 열린다. 기관 사이트는 WebFetch를 먼저 쓴다.
- europepmc.org 화면은 403이다. REST API `https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:<doi>&format=json&resultType=core`를 쓴다. doi.org, pubmed.ncbi.nlm.nih.gov는 정상이다.
- web.archive.org는 막혀 있다. 한국어판은 보관 링크를 요구하지 않는다.
- 끝내 원문을 열지 못하면 지어내지 않고 `TODO 확인 필요`로 남긴다.

### S3 초역
- 항목 형식은 KR-GUIDE.md 예제 그대로. 필드 6종(비용/쉽게/이득/근거등급/출처/비고)을 이 순서로 한 번씩.
- 비용태그 주석 줄(`<!-- 成本标签: ... -->`)은 원문 그대로 복사한다.
- **문체는 A(평어체) 중립**: 서술 `~다`, 권고 `~하세요`. 합니다체 변환은 S4 스크립트가 한다. 직접 합니다체로 쓰지 않는다.
- 의료 항목: DOI·PubMed·HR/RR/OR 원문 그대로.
- 법·제도 항목: 2-research.md에서 확인한 한국 조문·기관·금액으로 새로 쓴다. 원문의 사고방식(비용 대비 결과, 과정 비용까지 말하기)은 유지한다.
- 이식 불가 항목: 빼거나 "한국에는 이 제도가 없다"고 명시하고, 1-analysis.md에 이유를 남긴다.
- 원문에 없는 항목 추가: 한국에만 있는 위험이나 제도가 원문 절의 주제 안에 있을 때만 더한다. 1-analysis.md에 사유를 적는다.
- **의도적 차이 표시**: 항목을 빼거나 더했거나 DOI를 보강·삭제했으면 `3-draft.md` 도입부(첫 `### ` 줄 앞, 도입 문단 뒤)에 한 줄씩 단다. S5 검증은 이 표시가 없으면 항목 수·DOI 차이를 반려한다. 표시는 S4 문체 변환을 그대로 지나간다.
  - `<!-- kr-omit: N — 사유 -->`: 원문 `### N.` 항목을 뺐다. 여러 개면 여러 줄. 그 항목에 딸린 DOI는 따로 적지 않는다.
  - `<!-- kr-add: N — 사유 -->`: 한국어판 `### N.` 항목은 원문에 대응 항목이 없는 새 항목이다. N은 한국어판 번호다. 그 항목에만 있는 DOI는 따로 적지 않는다.
  - `<!-- kr-doi-add: <DOI> — 사유 -->`: 한국 진료지침처럼 원문에 없는 DOI를 더했다(KR-GUIDE 원칙 2).
  - `<!-- kr-doi-drop: <DOI> — 사유 -->`: 원문 DOI를 일부러 뺐다.
  - 사유는 1-analysis.md·2-research.md에 적은 이유를 짧게 옮긴다. 사유가 비면 무효다. 항목 블록 안에 두지 않는다(S7 항목 에이전트가 건드릴 수 있다).
- 갈아낸 항목의 비고에 확인일: `2026-10-07 법령 확인(국가법령정보센터)`.
- 교차 참조는 KR-GUIDE 「참조 표기」대로 쓴다. 같은 절은 `제M항(앵커어)`, 다른 절은 `제N절(주제)`, 다른 절의 항목은 `제N절 제M항(앵커어)`. 주제는 book-kr/README.md 표의 한국어 제목 그대로, 앵커어는 대상 항목의 한국어 제목에서 뽑는다. 대상 절이 아직 안 나왔어도 「(준비 중)」「다룰 예정」을 붙이지 않는다.

## 자체 검증

```bash
node .claude/skills/kr-verify/scripts/kr-fit.mjs kr-harness/chapters/NN/3-draft.md
grep -c '^### ' book/NN-*.md kr-harness/chapters/NN/3-draft.md
```

- kr-fit의 block은 전부 처리하고 warn도 읽는다(출처 줄의 원문 문헌 제목은 검사에서 빠진다). 의도된 비교는 `<!-- kr-fit-ok: 사유 -->`로 표시한다.
- 항목 수가 다르면 1-analysis.md에 사유가 있고, 도입부에 뺀 항목마다 `kr-omit`, 더한 항목마다 `kr-add` 표시가 있어야 한다.
- DOI 집합이 원문과 같은지 확인한다. 일부러 더하거나 뺀 DOI는 도입부에 `kr-doi-add`·`kr-doi-drop` 표시가 있어야 한다.

## 금지

- `book/`, 원본 `README.md`, `docs/`, `index.html`, `tools/`, `book-kr/` 수정 금지(book-kr/ 조립은 S8 스크립트가 한다).
- 중국 수치·조문을 한국어로만 옮기기 금지.
- 출처 없는 한국 수치 금지. "대체로 ~로 알려져 있다" 같은 완곡으로 근거 없는 주장 꾸리기 금지.
- 절 여러 개를 한 컨텍스트에서 처리 금지(절 1개 = 서브에이전트 1개).

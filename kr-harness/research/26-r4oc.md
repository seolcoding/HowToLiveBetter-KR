## T1. 제2항: 자기 상품만 파는 쇼핑몰(자사몰)의 「전기통신사업법」 부가통신역무 해당 여부
- 판정: 미해결
- 찾은 사실: 새 경로에서도 자사몰의 부가통신역무 해당 여부를 짚은 정부 안내·해석·판결은 없었다. 법제처 생활법령(easylaw.go.kr) 쇼핑몰 창업 가이드는 자사몰과 오픈마켓만 구분할 뿐 전기통신사업법을 언급하지 않고, easylaw 전체 검색에서 '부가통신' 히트 184건 중 생활법령 해설 본문은 0건, '쇼핑몰' 검색에서 법령해석례·판례·행정심판례 모두 0건이었다. law.go.kr 판례 DB에서 '부가통신사업'은 1건뿐이고(대법원 2020두50348, 선고 2023.12.21. — CP 접속경로 변경 사건으로 자사몰과 무관), '부가통신역무'·'통신판매중개'는 0건이었다. CRMS 보도자료 50건 전수 목록에도 관련 건이 없었다. 부수 확인: 신고 서식을 담은 「전기통신사업법 시행에 관한 과학기술정보통신부규정」(과기정통부고시 제2024-16호, 2024.4.17. 시행)이 존재하고 별지 '부가통신사업 신고증명서'가 있으나, 서식 본문은 POST·HWP로만 제공되어 '서비스 유형' 기재 문언(자사몰 표기 유무)은 확인하지 못했다. 2·3차 확인 건(법 제2조 제6호·제12호·제22조, 시행령 제30조 제1항, CRMS '전자상거래 서비스' 예시)은 그대로 유효하다.
- 원문 인용: 「쇼핑몰 창업자는 … 모든 과정을 직접 담당하는 개별쇼핑몰(자사몰)을 운영하거나, 통신판매중개업자가 운영하는 사이버몰(오픈마켓 등)에 입점하여 상품을 판매할 수 …」(법제처 생활법령 「온라인 쇼핑몰 창업ㆍ운영」 가이드 — 자사몰·오픈마켓 구분만 있고 전기통신사업법 언급 없음) ; '부가통신사업' 판례 검색 결과 totalCnt=1, 사건명 「시정명령등처분취소청구의소[콘텐츠 제공사업자(CP)의 접속경로 변경행위가 전기통신사업법령상 '전기통신서비스의 이용을 제한하는 행위'에 해당하는지 여부가 문제된 사건]」(대법원 2020두50348)
- 출처: 법제처 찾기쉬운 생활법령정보 「온라인 쇼핑몰 창업ㆍ운영」 https://www.easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=2985&ccfNo=1&cciNo=1&cnpClsNo=1 (2026-10-23); 국가법령정보센터 판례 DRF API https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=prec&type=XML&query=부가통신사업 (2026-10-23); 「전기통신사업법 시행에 관한 과학기술정보통신부규정」 https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000239436 (2024.4.17. 시행, 2026-10-23); 중앙전파관리소 보도자료 게시판 https://www.crms.go.kr/lay1/bbs/S1T30C34/A/77/list.do (2026-10-23). 미확인 경로: emsit 민원서식 파일 본문(HWP), 감사원 보고서, 공공데이터포털 '부가통신사업' 데이터셋, KCI 학술논문, 국회 의안정보 open API(서비스 ID 무효 오류)·likms(JS 렌더링)

## T2. 제3항: 인터넷 실시간 라이브 방송이 「영화비디오법」상 비디오물인지
- 판정: 부분 해결
- 찾은 사실: 실시간 라이브를 직접 다룬 판결·공식 해석은 이번에도 없었다. law.go.kr 판례 DRF 사건명 검색에서 '생방송'·'라이브'·'스트리밍' 0건, '실시간'은 무관한 국가배상 사건 1건뿐이었고, 영등위 ORS FAQ 8페이지 전체와 비디오 등급분류 신청안내에서도 실시간·라이브·생방송·중계·스트리밍 언급이 0건이었다(신청은 파일·'최종유통본' 제출 전제, 사용매체 선택지에 실시간 없음). 대신 간접 근거를 세 종류 새로 확보했다. 첫째, 3차에서 쓴 서울남부지법 2019노2493(웹하드 업로드 파일=비디오물, 유료 전송='유통')의 상고심인 대법원 2021도701(2022.11.17. 선고)이 그 법리를 수긍하고 상고를 기각했다 — 사건명 자체가 "인정된죄명: 영화및비디오물의진흥에관한법률위반방조"다. 둘째, 「영화비디오법 시행령」 제23조(대통령령 제36220호, 2026.3.24. 공포·시행)가 스포츠 경기 중계프로그램조차 '제작 또는 배급하는 온라인비디오물'로 규정한다 — 법령 체계 전반이 프로그램 단위·제작 전제이고 실시간 스트림 자체를 규율하는 문언은 어디에도 없다. 셋째, 현행 제2조 제12호의2 온라인비디오물 정의도 "시청에 제공할 수 있도록 제작된 비디오물"로 제작(고정)을 전제한다(법률 제21093호, 2025.11.11. 공포, 2026.5.12. 시행).
- 원문 인용: 「12의2. "온라인비디오물"이란 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 제2조제1항제1호에 따른 정보통신망(이하 "정보통신망"이라 한다)을 통하여 시청에 제공할 수 있도록 제작된 비디오물을 말한다.」(「영화 및 비디오물의 진흥에 관한 법률」 제2조 제12호의2, DRF API 직접 확인) ; 「가. 스포츠 경기의 중계프로그램을 동일한 내용으로 하여 제작 또는 배급하는 온라인비디오물 나. 스포츠 경기의 중계프로그램을 편집하여 제작 또는 배급하는 온라인비디오물」(같은 법 시행령 제23조 제1항 제3의2호, DRF API 직접 확인) ; 「… 원심의 판단에 … 정보통신망법 및 영화비디오법이 정한 각 양벌규정의 적용, 영화비디오법에서 정한 '비디오물'과 '유통'의 개념 및 적용, … 각 법리를 오해하거나 또는 판단을 누락하여 판결에 영향을 미친 잘못이 없다.」(대법원 2021도701, 2022.11.17. 선고 — 원심 서울남부지법 2019노2493, 상고 기각, DRF 판례본문 직접 확인)
- 출처: 「영화 및 비디오물의 진흥에 관한 법률」 https://www.law.go.kr/DRF/lawService.do?OC=test&target=law&MST=279649&type=XML (법률 제21093호, 2025.11.11. 공포, 2026.5.12. 시행, 2026-10-23 확인); 같은 법 시행령 https://www.law.go.kr/DRF/lawService.do?OC=test&target=law&MST=284811&type=XML (대통령령 제36220호, 2026.3.24. 공포·시행, 2026-10-23 확인); 대법원 2021도701 https://www.law.go.kr/DRF/lawService.do?OC=test&target=prec&ID=231969&type=XML (2022.11.17. 선고, 2026-10-23 확인); 영상물등급위원회 ORS FAQ https://ors.kmrb.or.kr/commission/faq_list.do (2026-10-23); ORS 비디오 등급분류 신청안내 https://ors.kmrb.or.kr/guide/video/info.do (2026-10-23). 미확인 경로: 국회 의안정보(open API 오류·JS), KCI·DBpia 학술논문(검색 도구 한도 초과), 법제처 해석례 사이트(접속 불가), 영등위 고시 원문(DRF 행정규칙 API 빈 응답)
- 반영 제안: 제3항 비고의 "인터넷 실시간 라이브 방송에도 이 판단이 그대로 적용되는지는 확인하지 못했습니다" 뒤에 "업로드 파일의 비디오물 해당·유료 전송의 유통 판단은 상고심에서 확정됐습니다(대법원 2021도701, 2022. 11. 17. 선고). 시행령도 스포츠 중계를 '제작 또는 배급하는 온라인비디오물'로 규정해(같은 법 시행령 제23조) 등급분류 대상이 프로그램 단위·제작 전제임을 보여 줍니다."를 덧붙이고, 출처에 대법원 2021도701과 시행령 제23조를 추가한다. 등급분류 규칙을 유료 다시보기에만 적용한 현행 처우는 그대로 유지하고, TODO는 "직접 근거 부존재(2026-10-23 판례·해석·영등위 실무 재검색)" 문구로 갱신해 유지한다.

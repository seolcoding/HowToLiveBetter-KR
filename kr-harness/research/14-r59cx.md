# 제14절 TODO 4차 조사 (2026-10-28)

## T1. 제10항: AI 중개·릴레이 사이트를 직접 겨냥한 국내 기관 경보
- 판정: 미해결
- 찾은 사실: 이전 기록에 구체 문서로 제시되지 않은 1차 자료 다섯 건의 관련 원문을 직접 열었다. 과기정통부·KISA 전망은 기업의 생성형 AI 보안 위험, KISA 약관은 자사 API 포털의 키 관리, 생성형AI 이용자 참여 플랫폼은 일반적인 개인정보 침해 유형을 다룬다. 가이드북은 업무상 기밀 입력 위험을, 학술논문 초록은 금융 자동화 에이전트의 외부 기능 통제를 다룬다. 이들 문구는 AI API 재판매·중계 사이트 이용자를 직접 겨냥한 국내 경보가 아니다. 이번에 확인한 범위에서 직접 경보를 찾지 못했으며, 경보의 부존재를 단정할 수는 없다.
- 원문 인용과 출처 (2026-10-28 확인):
  1. 과학기술정보통신부·한국인터넷진흥원, 「2025년 사이버 위협 전망」 9쪽: 「API 키 탈취, 데이터 유출, 플러그인 및 확장 프로그램 취약점 등 대표적인 위험 요소이다.」 기업의 생성형 AI 이용에 관한 전망이다. https://www.oka.go.kr/attach/cms/board/2025/03/946ADF549CA54509AB6AC4580A3D3C6E.pdf
  2. 한국인터넷진흥원, 정보보호 API 공유포털 서비스 이용약관 제13조 제2항: 「API Key가 유출된 것으로 의심될 경우, 이용자는 즉시 포털을 통해 해당Key를 재발급받거나 폐기하고, 관련 사실을 포털 관리자에게 알려야 합니다.」 이 포털 이용 약관이며 부칙에 2026-06-01 시행이라고 적혀 있다. https://security-api.kisa.or.kr/portal/content/terms-service
  3. 생성형AI 이용자 참여 플랫폼, 「생성형AI위험성 안내」: 「AI의 학습 과정에서 이용자 관련 데이터를 임의로 수집하거나응답 과정에서 특정인의 개인정보를 유출·노출」. 개인정보 침해 유형의 일반적 설명이다. 페이지의 게시일은 확인하지 못했다. https://ai.wiseuser.go.kr/report/guidance.do
  4. 「생성형 AI 윤리 가이드북」 36쪽: 「생성형 AI와 대화할 때 회사 정보를 올리면 자칫 기밀 정보가 유출될 수 있고, 경우에 따라 형사적, 민사적 책임을 져야 할 수 있습니다.」 업무상 기밀 입력에 관한 일반적인 안내다. 작성자에 한국지능정보사회진흥원 담당자가 포함되어 있다. 발행일은 확인하지 못했다. https://ai.wiseuser.go.kr/uploads/information/%EC%83%9D%EC%84%B1%ED%98%95_AI%EC%9C%A4%EB%A6%AC_%EA%B0%80%EC%9D%B4%EB%93%9C%EB%B6%81.pdf
  5. 김광모, 「금융 자동화 에이전트의 외부 기능 연계 보안통제 모델 연구」, 한국차세대컴퓨팅학회 논문지 22권 3호(2026), 초록: 「이 과정에서 과권한 실행, 민감정보 유출, 비인가 외부 전송, 기능 오염, 감사 추적 곤란과 같은 보안위험이 확대될 수 있다.」 금융 에이전트의 외부 기능 실행 통제에 관한 학술 연구이며 기관 경보가 아니다. 초록만 확인했다. https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART003355462
- 열람 한계: 전북교육청 게시물은 웹 열기에서 cache miss, 고용24 제안서와 나라장터 문서는 시간 초과로 열리지 않았다. 검색 결과 요약은 확인 근거로 쓰지 않았다.
- 반영 제안: TODO 유지. 제10항 비고와 출처에 이 자료들을 중개 사이트 직접 경보로 추가하지 않는다. 남은 쟁점은 국내 기관이 제3자 AI API 재판매·중계 사이트 이용자의 위험을 직접 경고한 원문이 있는지다.

# 제26절 TODO 4차 조사 (opencode glm-5.3-flash, 2026-10-24)

본문 맨 끝 TODO 2건(제2항 자사몰, 제3항 실시간 라이브)을 2차~49차 기록에 없던 경로로 다시 팠다. 이번에 새로 연 경로: 법제처 법령해석례 DB 전문검색(law.go.kr DRF target=expc — 지금까지 목록 화면만 시도되고 API 검색은 안 됐다), 지방 전파관리소(서울·부산 등 10개) 자체 누리집 존재 여부, 국회도서관 법안정보 open API 법안명 검색, law.go.kr 판례(prec) 조합 검색(온라인비디오물·쇼핑몰+부가통신), 문화체육관광부 2023. 3. 28. 보도자료 원문(첨부 HWPX 텍스트 추출 — 지금까지 본문 화면만 시도되고 본문은 첨부파일에 있었다), 영등위 보도자료 게시판 직접 접근(kmrb.or.kr 차단 해제 확인), 방송미디어통신심의위원회 심의의결서·통신심의 회의록. 서브에이전트 2개(general)가 조사했고, 아래 원문 인용 가운데 핵심은 오케스트레이터가 직접 다시 열어 확인했다(해석례·판례는 DRF, 보도자료는 HWPX 내려받아 텍스트 추출, 영등위·CRMS는 HTML). URL 확인일은 2026-10-26이다. 본문은 고치지 않았다.

'부가통신역무' 3건(17-0330 전화번호 제공의무, 08-0135 지방세 관허사업, 08-0442 KT 공공기관 여부)도 쇼핑몰과 무관하다. 둘째, 지방 전파관리소 10곳(서울·부산·광주·강릉·대전·대구 등)은 자체 누리집이 없고 중앙전파관리소(crms.go.kr) 안의 지소 소개 페이지(지소소개·지소장인사말·조직안내 메뉴뿐)로만 존재한다. 부가통신 안내를 내는 창구는 CRMS 본안내·리플렛·과기정통부 전자민원센터(emsit.go.kr)뿐임이 구조로 확인됐다. CRMS 현행 안내 페이지 전체에서 오픈마켓·자사몰·쇼핑몰 문언은 0회다(「오픈마켓 입점 제외」 문구는 카드뉴스·리플렛에만 있고 안내 페이지에는 없다 — 본문 비고의 출처 서술과 모순 없음). 셋째, 국회도서관 법안정보 API에서 법안명에 '부가통신'이 든 법안은 제20~22대 0건이다. 부수로, law.go.kr 판례 검색에서 나온 서울행정법원 2012구합18059·서울고등법원 2012누35414(지마켓 오픈마켓)는 이미 알려진 대법원 2013두11086(2013. 9. 26. 선고, 파기환송)의 원심 연쇄로 확인됐다. 이 사건은 조세특례제한법 세액감면의 업종 분류가 쟁점이고 대상도 오픈마켓이라, 자사몰-부가통신역무 문제의 근거로 쓸 수 없다.

## T2. 제3항: 인터넷 실시간 라이브 방송이 「영화비디오법」상 비디오물인지
- 판정: 부분 해결
- 찾은 사실: 실시간 라이브를 비디오물로/아니로 직접 다룬 판결·해석·규정 문언은 이번에도 0건이었으나, 규제기관 문서를 세 종류 새로 원문 확보해 '등급분류 대상은 완성 제공물'이라는 제도 구조를 강화했다. 첫째, law.go.kr 판례 사건명 검색에서 '온라인비디오물'은 0건이다. '비디오물 등급분류' 9건(2008도5282, 2008도7769, 2009도321, 2007노1626, 2007도7961, 2007도6775, 2007도2094, 2007도796, 2006노1519)은 전부 2006~2009년 DVD 등급분류위반 형사사건으로, 온라인비디오물 제도(2023. 3. 28. 시행) 이전 사건이고 실시간과 무관하다. 둘째, 문화체육관광부 2023. 3. 28. 보도자료(「온라인동영상서비스(OTT) 사업자, 콘텐츠 등급 직접 정한다」)의 본문이 첨부파일(HWPX)에 있다는 것을 찾아 원문을 처음 전문 확보했다. 소제목은 「청소년 보호계획 심사, 실시간 모니터링, 정기 업무 평가로 자체등급분류사업자 관리‧감독 철저」이고, '실시간 모니터링'은 등급분류를 마친 콘텐츠의 사후관리(등급 조정 요구·직권 재조정)를 가리킨다. 이전 차수에서 원천을 확인하지 못해 반려했던 '실시간 모니터링단' 계열 문언의 정당한 1차 출처가 이 보도자료다. 셋째, 영등위 보도자료 게시판(kmrb.or.kr — 이번 차수에는 차단 없이 직접 열림) 목록 스캔에서 실시간 방송을 등급분류 대상으로 언급한 건은 0건이다. '실시간'이 든 보도자료 2건(2024. 6. 26., 2025. 12. 22.)은 모두 「OTT 자체등급분류 영상물의 등급 적절성, 위법사항 실시간 점검」이란 모니터단(사후관리) 문맥이고, 앞뒤 문맥도 「사업자가 자체적으로 등급을 분류한 후 서비스되는 영상물에 대한 신속한 사후관리 대응체계」다. 부수로, 방송미디어통신심의위원회 심의의결서 게시판과 통신심의 소위원회 회의록(2026년 제48차)에서 영비법 비디오물 문언은 0회로, 실시간 방송 심의 실무가 망법 사후심의에 머문다는 이전 확인과 일치했다. 법제처 해석례 목록검색은 DRF·웹 화면 모두 검색어 파라미터를 처리하지 않아 실패 확정이다(r3에서 상세 1건 26-0262를 확보한 것이 유일).

## T1. 제10항: 한국 정부·기관의 'AI 중개(릴레이) 사이트' 겨냥 공식 경보
- 판정: 미해결
- 찾은 사실: 2026-10-27 기준으로도 'AI 중개(릴레이) 사이트'(LLM API 재판매·중계)를 직접 겨냥한 국내 공공기관 경보는 찾지 못했다. 이번에 새로 본 범위는 아래와 같다.
  ① KISA 보호나라 보안공지(B0000133) 1쪽 목록. 2026-10-26까지 올라온 15건의 제목에는 중개·중계·프록시·릴레이가 없었다. 이전 기록에 글 번호가 없던 두 건은 본문을 열었다. 「개발 운영 환경의 자격증명 노출에 따른 침해사고 예방 강화 요청」(nttId=72132, 2026-07-16)은 API 키 같은 자격증명이 코드 저장소·협업도구에 노출되거나 개발자 단말에서 탈취되는 사고를 다룬다. 「최근 사이버공격 대비 기업 보안강화 권고」(nttId=72207, 2026-10-03)는 웹·API 취약점과 노출된 인증정보를 먼저 점검하라고 권고한다. 두 건 모두 대상이 기업·기관이어서 개인 독자가 할 일은 없다. AI 중개 사이트에 키나 코드를 넘기는 위험도 다루지 않는다. 본문에 이미 들어간 「AI 개발도구 위장 악성코드 유포 주의 권고」(72133)는 다시 보지 않았다.
  ② 과기정통부 보도자료 목록(2026-10-22~10-26 게시분)에는 「㈜더존비즈온 침해사고 조사 착수」 같은 글이 있었다. AI 중계를 다룬 글은 찾지 못했다.
  ③ 개인정보보호위원회 보도자료 목록(2026-10-01~10-23)에는 「PHP 보안 취약점 관련 개인정보 유출 예방조치 당부」, 「외부 설문도구 이용 시 개인정보 처리 준수 사항」, 「제5차 인공지능책임관(CAIO) 협의회 개최」가 있었다. AI 중계를 다룬 글은 찾지 못했다.
  ④ WebSearch 1회. 국내 기관 결과는 찾지 못했다. 해외 결과로 Cloud Security Alliance 연구 노트 「The Shadow Relay Market: LLM API Reselling and Fraud Risk」(2026-07-29)가 나왔다. CSA는 업계 단체라 1차 공공 출처가 아니고, 본문도 열지 않았다. 후보로만 적는다. 이전 기록에 있는 CSA 2026-04-16 노트와는 다른 문서다.
  ⑤ korea.kr 보도자료 키워드 검색은 curl로 검색어가 적용되지 않았다. 최신 목록만 돌아와서 결과를 판단하지 못했다.

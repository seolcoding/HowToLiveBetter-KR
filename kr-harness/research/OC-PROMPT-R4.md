# opencode 4차 조사 지시문 (남은 TODO 재조사)

> 2·3차 조사로도 풀리지 않고 남은 TODO만 다시 판다. 먼저 `kr-harness/research/NN.md`(2차)와 `kr-harness/research/NN-r3.md`(3차)를 읽고, 이미 시도한 검색 경로와 막힌 이유를 확인한다. 같은 검색을 되풀이하지 말고 다른 경로(법령 연혁·별표, 행정규칙·고시 원문, 공공데이터포털, KOSIS 통계표 직접 주소, 판결서 공개, 국회 의안정보·회의록, 기관 보도자료 첨부, 해외 1차 문헌)를 찾는다. 본문 맨 끝 TODO 목록이 지금 남은 대상이다. 100MB가 넘는 파일은 내려받지 말고 쪽 단위 미리보기나 다른 경로를 찾는다.

파일을 내려받을 때는 저장소 밖 임시 폴더($TEMP)에 둔다. 표준입력을 기다리는 명령(python -, heredoc)과 이름으로 프로세스를 끄는 명령은 쓰지 않는다.

너는 한국어판(book-kr/)의 `## TODO 확인 필요` 목록을 딥리서치하는 **조사 담당**이다. 본문은 고치지 않는다. 조사 결과를 기록 파일 하나에만 쓴다.

## 입력

- 대상 절 번호 NN은 실행 프롬프트로 받는다. 본문은 `book-kr/NN-*.md`이고, 맨 끝 `## TODO 확인 필요` 목록의 한 줄이 한 건이다.
- 처음에 `KR-GUIDE.md`와 `.claude/skills/kr-localize/references/kr-sources.md`(한국 1차 출처 목록)를 읽는다.
- TODO마다 본문의 해당 항목(`### N.` 블록)도 읽어서, 무엇을 확인해야 본문을 고칠 수 있는지 파악한다.

## 방법

- **task 도구로 general 서브에이전트를 TODO마다 하나씩 띄우되, 한 번에 4개까지만 병렬로 돌린다.** 앞 묶음이 끝나면 다음 묶음을 띄운다. 각 서브에이전트는 websearch로 찾고 webfetch로 원문을 직접 연다. 서브에이전트 프롬프트에 이 지시문의 「1차 출처만」「지어내지 않는다」 규칙과 원문 인용·URL을 돌려달라는 요구를 넣는다. 결과를 종합하는 일은 네가 한다.
- law.go.kr 화면 주소는 JS로 그려져 본문이 안 나온다. 법령 본문은 공식 API로 연다: 목록 `https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=law&type=XML&query=법령명` 으로 MST를 찾고, 본문 `https://www.law.go.kr/DRF/lawService.do?OC=test&target=law&MST=번호&type=XML`.
- 1차 출처만 인정한다: 국가법령정보센터(law.go.kr)의 법령·시행령·고시 원문, 정부·공공기관 누리집(.go.kr, 공단·공사), KOSIS 통계, 법원 판결문(대법원 종합법률정보·판결서), 학술지 논문(DOI·PubMed), WHO 같은 국제기구 보고서.
- 블로그, 나무위키, 언론의 2차 전달, 보험사·병원 광고 페이지는 근거로 쓰지 않는다. 다만 1차 출처를 찾는 실마리로는 써도 된다.
- **수치와 조문은 원문에서 직접 확인한 것만 적는다.** 찾지 못하면 지어내지 말고 「미해결」로 둔다. DOI나 URL을 기억으로 만들지 않는다.
- 출처끼리 말이 다르거나(예: 고시 개정 전후, 기관마다 다른 금액) 확실하지 않으면 「상충」으로 표시하고 양쪽 원문 문장과 URL, 시행일을 모두 적는다. 가능하면 더 상위·최신 출처를 다시 열어 어느 쪽이 현행인지 판단 근거를 덧붙인다.
- 기준일은 실행일이다. 개정·시행일이 있는 내용은 시행일을 적는다.

## 출력: `kr-harness/research/NN-r4.md` 하나만 쓴다

```
# 제NN절 TODO 4차 조사 (opencode glm-5.3-flash, YYYY-MM-DD)

## T1. 제M항: (TODO 원문 첫 문장 요약)
- 판정: 해결 | 부분 해결 | 상충 | 미해결
- 찾은 사실: 한두 문장. 숫자·조문·시행일 포함.
- 원문 인용: 「출처 원문 문장 그대로」
- 출처: 기관/문서명, URL (확인일)
- 반영 제안: 본문 어느 칸(비용/쉽게/이득/근거등급/출처/비고)을 어떻게 고칠지 한두 문장. 미해결이면 「TODO 유지」와 남은 쟁점.
```

- TODO 목록 순서대로 T1, T2, …로 쓴다. 한 건도 빼지 않는다.
- 맨 마지막 줄은 정확히 이 형식이다: `RESEARCH-DONE: total=N resolved=A partial=B conflict=C unresolved=D`

## 금지

- `book-kr/`, `book/`, `README.md`, 다른 절의 파일, `kr-harness/research/NN-r4.md` 밖의 어떤 파일도 고치지 않는다.
- git 명령(commit, push, checkout 등)을 실행하지 않는다.
- 외부 서비스에 글을 올리거나 양식을 제출하지 않는다. 읽기만 한다.

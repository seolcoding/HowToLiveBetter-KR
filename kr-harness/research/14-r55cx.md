## T1. 제10항: AI 중개·릴레이 사이트를 직접 겨냥한 국내 기관 경보
- 판정: 미해결
- 찾은 사실: 기존 기록에 없던 1차 문서 5건의 관련 본문을 직접 열었다. 경기도교육청의 학생용·교사용 자료는 각각 비슷한 이름의 비공식 사이트 주의와 공식 사이트 이용 교육을 다루지만, AI API 재판매·중계 사이트의 이용자 피해를 직접 경고하지 않는다. 국방전직교육원의 제안요청서는 기관 시스템의 API 게이트웨이 구축 요구다. 미국 NIST의 글과 메릴랜드주 지침은 각각 에이전트 자격증명 및 MCP 서버 위험에 관한 해외 자료다. 이번에 열어 본 범위에서는 요구한 국내 직접 경보를 확인하지 못했다. 경보가 존재하지 않는다고 단정할 수는 없다.

# 제10절 TODO 4차 조사 (2026-10-28)

기준: 본문 끝의 세 TODO. 이전 10절 조사 및 반영 기록을 참고하여 이미 막힌 판례 검색·국회 의안·법령해석 경로는 반복하지 않았다. 이번에는 웹 검색으로 복지부 원문 PDF와 법원 공개 자료를 열었다. 검색 결과 미발견은 판결이 없다는 증거가 아니다.

## T1. 제19항: 성적 지향을 숨긴 혼인의 취소·이혼·배상 판결
- 판정: 미해결
- 찾은 사실: 사건번호가 확인되는 해당 판결문을 새로 직접 열지 못했다. 법원 공식 자료의 검색 결과 후보를 열었으나 방화벽 차단 화면이 반환되어 판결 내용은 확인하지 못했다. 변호사 사무소의 사례 소개는 판결문 원문이 아니므로 근거로 사용하지 않았다.
- 원문 인용: 확인한 해당 판결문 없음. 법원 사이트 응답은 「The request / response that are contrary to the Web firewall security policies have been blocked.」였다.
- 출처: 대법원 사이트 접근 응답 https://www.scourt.go.kr/sjudge/1641433937511_105217.pdf (2026-10-28). 이 주소는 검색 결과로 발견한 다른 혼인무효 판결 후보이며, 해당 사건의 판결문 근거가 아니다.
- 반영 제안: TODO 유지. 사건번호가 있는 해당 판결문을 직접 확보해야 한다. 검색 실패나 방화벽 차단을 판결의 부존재로 쓰지 않는다.

## T2. 제19항: 부모 안심 목적 형식혼의 혼인무효·불실기재 판결
- 판정: 미해결
- 찾은 사실: 부모를 안심시키려는 목적을 직접 다룬 판결문을 새로 확인하지 못했다. 대법원 판례속보 후보를 열었으나 방화벽 차단 화면이 나와 본문을 확인할 수 없었다. 검색 결과 요약만으로 판결의 사실관계나 결론을 인용하지 않는다.
- 원문 인용: 확인한 해당 판결문 없음. 법원 사이트 응답은 「The request / response that are contrary to the Web firewall security policies have been blocked.」였다.
- 출처: 대법원 판례속보 접근 응답 https://scourt.go.kr/portal/news/NewsViewAction.work?gubun=4&searchOption=&searchWord=&seqnum=8116 (2026-10-28). 이 주소는 해당 부모 안심 사안의 판결문 근거가 아니다.
- 반영 제안: TODO 유지. 실제 부모 안심 목적과 그에 대한 판단이 기재된 판결문을 확보해야 한다. 다른 목적의 판결로 해당 사안의 결론을 단정하지 않는다.

## T3. 제18항: 임의후견인이 의료법상 법정대리인으로 수술에 동의할 수 있는지
- 판정: 부분 해결
- 찾은 사실: 보건복지부의 2018년 국가치매관리위원회 자료는 후견 일반의 종류를 설명하면서 법정후견인과 임의후견인을 구분한다. 그러나 이 자료는 의료법 제24조의2의 법정대리인이라는 표현을 해석하거나 임의후견인의 수술 동의 가능 여부를 직접 판단하지 않는다. 따라서 일반적 분류만으로 의료법상 결론을 내릴 수 없다.
- 원문 인용: 「(종류) 선임의 방법과 대리권의 범위에 따라 성년․한정․특정 후견인(이상 법정후견인)과 임의후견인으로 구분」
- 출처: 보건복지부, 「2018년도 제1차 국가치매관리위원회 개최」 붙임 2, 6쪽, 2018-04-12 배포, https://www.mohw.go.kr/upload/140/201804/1523612046896_20180413183406.pdf (2026-10-28 직접 열람). 당시 제도 개요이며 의료법 해석이나 현행성에 대한 별도 확인은 아니다.
- 반영 제안: TODO 유지. 필요하면 비고에 2018년 복지부의 일반적 후견 분류를 그 범위로만 소개할 수 있다. 의료법 제24조의2에 대한 관계기관의 직접 해석 또는 관련 판결을 확인해야 한다.

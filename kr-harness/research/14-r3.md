- 판정: 미해결
- 찾은 사실: 2026-10-22 기준 한국 정부·기관의 'AI 중개(릴레이) 사이트'(LLM API 재판매·리버스 프록시 중개 서비스) 직접 겨냥 공식 경보는 존재하지 않는다. 이번에 새로 확인한 범위: ① KISA 보호나라 보안공지(bbsId=B0000133, 2차와 다른 새 키워드 LLM·API 키·생성형·챗GPT·딥시크·MCP·토큰 등) 2026-01-06~2026-10-22 게시물 전수(2332~2577호)와 2024-06~2025-02 키워드 확인 — AI 관련으로 걸린 것은 「LiteLLM 제품 사용 주의 권고」(2026-04-01, LLM 프록시 소프트웨어의 PyPI 공급망 오염 경보로 중개 서비스와 다름), 「개발도구 공급망을 통한 연쇄적 사이버 공격주의 권고」(2026-04-01), 「Anthropic 제품 보안 업데이트 권고」(2026-03-06, Claude Code CVE 2건), 「개발 운영 환경의 자격증명 노출에 따른 침해사고 예방 강화 요청」(2026-07-16), 「생성형 AI 사용 관련 주의 보안권고」(2025-02-07)뿐이고 전부 중개 사이트 경보가 아니다(원문 전부 직접 열어 확인). ② KISA 보도자료(kisa.or.kr/402) — 2026년 AI 관련은 행사·국제협력 소식(2026-08-31 모의해킹 대회, 2026-09-18 WEF·싱가포르 CSA 협력)뿐, 중개 건 없음. ③ 개인정보보호위원회 보도자료 2026년 목록 19페이지 — 가이드 발간(2026-05-19), AI 범죄 대응 범부처 협의체(2026-06-26) 등 정책 소식뿐, 중개 건 없음. ④ 국가사이버안보센터(ncsc.go.kr)와 과학기술정보통신부(msit.go.kr)는 누리집이 각각 토큰+JS 동적 로딩과 '시스템 점검 중' 페이지로 막혀 게시물 목록 직접 열람에 실패했다(이번에도 확인 못 함). ⑤ 해외에서도 소비자 겨냥 중개 사이트 경보는 없었고(FBI IC3 PSA 2025년 38건·2026년 26건 전수), 가장 근접한 1차 출처는 CISA·NSA·FBI 합동 경보 AA26-251A(2026-09-08)다. 이 경보는 LLM API 프록시 회색시장('transfer stations')을 국가행위자 증류(distillation) 공격 경로로 공식 지목한 것이지 이용자 대상 중개 사이트 경보는 아니다. 본문 비고의 「한국 정부가 중개 사이트를 겨냥해 내린 경보는 아직 없습니다」는 2026-10-22 기준으로도 유효하다.

# 제14절 TODO 4차 조사 (2026-10-28)

## T1. 제10항: AI 중개·릴레이 사이트를 직접 겨냥한 국내 기관 경보
- 판정: 미해결
- 찾은 사실: 새 1차 경로인 연구자들의 arXiv 프리프린트 초록을 직접 열었다. Ji 등의 2026-08-21 제출 논문은 재판매 서비스 사이의 숨겨진 의존성을 조사하고 39개 재판매 엔드포인트를 측정했다고 설명한다. Xie 등의 2026-06-15 제출 논문은 API 라우터가 클라이언트와 별도의 상위 연결을 맺는 구조에서 평문에 접근할 수 있다고 설명한다. 두 문서는 국내 기관의 이용자 경보가 아니며, 초록만 확인했고 동료심사 여부는 확인하지 못했다. 이번에 국내 직접 경보를 확인하지 못했지만, 경보가 존재하지 않는다고 단정할 수는 없다.
- 원문 인용: 「a user's request may traverse undisclosed upstream resellers」(Ji 등 초록); 「A router terminates the client's transport-layer security session and opens a separate upstream session」(Xie 등 초록).
- 출처: Ji 등, 「Uncovering and Understanding Hidden Dependencies in the LLM API Reseller Ecosystem via Prefix-Cache Side Channels」, https://arxiv.org/abs/2608.20732 (2026-10-28 확인); Xie 등, 「The Proxy Knows Too Much: Sealing LLM API Routers with Attested TEEs」, https://arxiv.org/abs/2606.16358 (2026-10-28 확인).
- 반영 제안: TODO 유지. 두 논문은 해외 연구로 국내 직접 경보를 대신하지 못하므로 본문에 경보로 추가하지 않는다. SPRi RE-171 상세 페이지 https://www.spri.kr/posts/view/23723?code=data_all&study_type=research 는 웹 도구에서 열리지 않아 첨부 원문과 맥락을 확인하지 못했다. 국내 기관의 직접 경보가 확인되면 발행 기관과 원문을 다시 확인한다.

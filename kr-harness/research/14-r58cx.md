# 제14절 TODO 4차 조사 (2026-10-28)

## T1. 제10항: AI 중개·릴레이 사이트를 직접 겨냥한 국내 기관 경보
- 판정: 미해결
- 찾은 사실: 이전 기록에 없던 1차 문서 다섯 건의 본문을 직접 열었다. 금융위원회의 두 자료는 금융회사의 AI 활용과 제3자 위험관리 방안이고, 미국 기관의 세 자료는 금융기관의 제3자 관리 또는 일반적인 API 보호 지침이다. 어느 것도 국내 기관이 AI API 재판매·중계 사이트의 이용자를 직접 겨냥해 발령한 경보는 아니다. 이번에 확인한 범위에서 직접 경보를 찾지 못했으며, 경보의 부존재를 단정할 수는 없다.
- 원문 인용과 출처 (모두 2026-10-28 확인):
  1. 금융위원회, 금융권 AI 협의회 보도자료(2025-12-22), 금융분야 AI 가이드라인 개정안 표: 「제3자 IT리스크 관리」. 금융안정성 원칙에 관한 개정안이다. https://www.fsc.go.kr/no010101/85908
  2. 금융위원회, 금융분야 망분리 개선 로드맵 보도자료(2024): 「제3자 리스크」에 대한 관리 강화 방안을 설명한다. 금융권의 제3자 정보처리 위탁에 관한 정책 설명이다. https://www.fsc.go.kr/no010101/82885
  3. 미국 뉴욕주 금융서비스국, 「Guidance on Managing Risks Related to Third-Party Service Providers」(2025-10-21): 「The Guidance does not impose new requirements or obligations on Covered Entities」. 규제 대상 금융기관의 제3자 서비스 제공자 관리 지침이다. https://www.dfs.ny.gov/industry-guidance/industry-letters/il20251021-guidance-managing-risks-third-party
  4. 미국 국립표준기술연구소, 「Guidelines for API Protection for Cloud-Native Systems」(2025-06, 2026-03-13까지 갱신 반영), 2.5절: 「Unintentionally leaking business data via APIs is closely related to missing, incorrect, or insufficient authorization」. 클라우드 시스템의 일반 API 보호 지침이다. https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-228-upd1.pdf
  5. 미국 신용조합감독청, 「Artificial Intelligence (AI)」(2026-04-28 수정): 「Credit unions using AI provided by a third party vendor must conduct appropriate due diligence」. 미국 신용조합의 AI 공급자 관리에 관한 안내다. https://ncua.gov/regulation-supervision/regulatory-compliance-resources/artificial-intelligence-ai
- 열람 한계: 금융위원회 가상자산 API 관련 게시물 https://www.fsc.go.kr/po010103/86809 은 웹 도구에서 열리지 않아 본문 확인 근거로 쓰지 않았다.
- 반영 제안: TODO 유지. 제10항 비고·출처에 위 문서들을 중개 사이트 직접 경보로 추가하지 않는다. 남은 쟁점은 국내 기관이 제3자 AI API 재판매·중계 사이트 이용자의 위험을 직접 경고한 원문이 있는지다.

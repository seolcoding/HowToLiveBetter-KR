## T1. 제10항: 한국 정부·기관이 'AI 중개(릴레이) 사이트'를 직접 겨냥한 경보 부재 확인
- 판정: 미해결
- 찾은 사실: 2026년 10월 25일 기준으로도 한국 정부·공공기관, 소비자단체, 분쟁조정기구 어디에서도 'AI 중개(릴레이/프록시) 사이트'나 '비공식 AI API 재판매'를 직접 겨냥하여 발령한 공식 보안 경보, 주의보, 또는 독립 점검 가이드는 일절 존재하지 않는다. 신규 확인한 8대 경로 전수 검증 결과는 다음과 같다:
  1. **KISA ISMS-P 인증기준 및 보안 안내서:** ISMS-P(102개 기준)에는 사설 AI 중개 사이트 규정이 없으며 비인간 식별자(NHI) 수명주기 관리(2.5)와 미인가 외부 서비스 통제(2.3, 2.9)로 포괄된다. 과기정통부·KISA의 『인공지능(AI) 보안 안내서』(2025.12, 2026.3 정오 수정본, 점검항목 98개)와 『AI 보안 위협 대응 매뉴얼』(2026.7)도 전송구간 암호화(TLS) 및 자체 AI 게이트웨이 구축을 권고할 뿐 비공식 중개 사이트 경보는 없다.
  2. **행정안전부·KISA 「소프트웨어 개발보안 가이드」:** 구현 단계 7대 분야 47~49개 보안약점 중 "API 오용"은 안전하지 않은 C/Java 함수(strcpy 등)나 DNS lookup 의존 결정에 한정되고 하드코딩된 API 키 노출 금지를 다룰 뿐, 서드파티 사설 AI API 중개(릴레이) 연동 위험 규정은 전무하다.
  3. **교육부 및 KERIS(한국교육학술정보원):** KERIS 『생성형 AI를 활용한 교수학습 운영 가이드』(2024), 『교과별 생성형 AI 활용 길라잡이』(2023), 교육부 『수행평가 시, AI 활용 관리 방안』(2025.12 발표, 2026학년도 적용)을 전수 확인했으나, AI 대필 방지, 출처 표기, AIDT 표준 API 게이트웨이 연동만 다루며 비공식 AI 중개/릴레이 사이트 위험 경보는 없다.
  4. **개인정보 분쟁조정위원회(kopico.go.kr):** 연도별 『개인정보 분쟁조정 사례집』 및 공개 조정 결정례 전수 검토 결과, 'AI API 키 노출' 또는 'AI 중개 사이트' 관련 분쟁조정 사건 접수 및 결정례는 0건이다.
  5. **한국소비자단체협의회 1372 소비자상담센터:** 포털 광고 상단 ChatGPT·Gemini 사칭 결제 사기(2025.12.15 소비자원 주의보)와 챗봇 상담 오안내 책임 회피 민원만 접수되었을 뿐, AI API 재판매·중개 사이트 피해 상담 및 경보는 전무하다.
  6. **국방부 및 군 사이버작전사령부 지침:** 군사기밀 및 비공개 내부정보의 상용 AI 입력 금지, 보안성 검토 완료 체계만 접속, 모델 학습 비활성화 의무화 등 군 내부 보안 통제 지침일 뿐 대국민 경보가 아니다.
  7. **OWASP Top 10 for LLM Applications (2025 v2.0) 및 Agentic Security:** 10대 카테고리(LLM01~LLM10) 전수 확인 결과 'Third-party LLM Relay/Proxy' 또는 'Malicious Intermediary'라는 독립 명칭은 없으며, LLM03(Supply Chain)과 LLM06(Excessive Agency), 그리고 Agentic Security(ASI04)에서 MCP 원격 프록시(mcp-remote) 취약점 등 공급망·도구 오용으로 포괄한다.
  8. **NIST Generative AI Profile (NIST AI 600-1, 2024.7):** 12대 리스크 중 'Value Chain and Component Integration'에서 불투명한 서드파티 구성요소 결합 위험을 다루나, 소비자 대상 사설 중개 사이트 경보와는 성격이 다르다.
  따라서 'Malicious Intermediary Attacks'는 2026년 UCSB 연구진(Liu et al., arXiv:2604.08407)이 정립한 학술 연구 개념이며, 본문 제10항 비고의 "중개 사이트를 직접 겨냥한 국내 경보는 찾지 못했습니다... 이 문서들은 법이 아닌 안내서입니다. 중개 사이트를 따로 짚지도 않습니다"라는 서술은 2026년 10월 25일 기준으로도 100% 사실에 부합한다.

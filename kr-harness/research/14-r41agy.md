## T1. 제10항: 한국 정부·기관의 'AI 중개(릴레이) 사이트' 겨냥 공식 경보
- 판정: 미해결
- 찾은 사실: 2026년 10월 25일 기준으로도 한국 정부·공공기관이 'AI 중개(릴레이) 사이트'(LLM API 재판매, 리버스 프록시, 서드파티 API 키 중개 서비스)를 직접 겨냥하여 발령한 공식 보안 경보나 이용자 피해주의보는 일절 존재하지 않는다. 이번에 새로 개척한 8개 경로 전수 검증 결과는 다음과 같다:
  1. **국회입법조사처(nars.go.kr) [이전 조사 봉쇄 해소]:** 이전 3·4차 조사에서 "웹 뷰어 DRM 차단으로 목차만 열람"으로 남아 있던 정책연구용역 보고서 『AI로 인한 새로운 보안 위험과 대응에 관한 국내외 입법ㆍ정책 비교 연구』(2026-09-07, 237쪽, `260907-AI보안위험대응-최종보고서.pdf`, seq=49603) 원문 PDF(3.54MB)를 직접 확보해 237쪽 전수를 전산 텍스트 파싱·검색했다. `중개`·`릴레이`·`relay`·`프록시`·`proxy`는 237쪽 전체에서 **0건(전무)**이며, `API 키`·`API키`·`api key` 역시 **0건(전무)**이다. `API`는 5개 쪽(68, 87, 89, 97, 213쪽)에 나타나나 "AI 환경은 클라우드 서비스, 외부 API 등과 연동" 등 일반적 시스템 아키텍처 기술에 불과하여, 이전 조사의 최대 미해결 의문점이던 입법조사처 보고서 내 중개 사이트 경보 존재 가능성이 완전히 배제되었다.
  2. **방송통신위원회(kcc.go.kr) 및 와이즈유저(wiseuser.go.kr):** 방통위는 2025-02-28 「생성형 인공지능 서비스 이용자 보호 가이드라인」(2025-03-28 시행)을 발표하고 와이즈유저 내 '생성형 AI 이용자 참여 플랫폼(ai.wiseuser.go.kr)' 및 '온라인피해365센터'를 통해 피해 상담 창구를 운영 중이나, 통신분쟁조정 및 보도자료 전수 확인 결과 AI API 중개·리버스 프록시 관련 경보는 없다.
  3. **과학기술정보통신부(msit.go.kr) 및 KISA:** 과기정통부와 KISA는 2026-07-08 『AI 보안 위협 대응 매뉴얼』(5대 영역 21개 세부 위협: 부적절한 도구 설계 Inappropriate Tool Design, 에이전트 하이재킹 Agent Hijacking, 공급망 위협 등) 및 『AI 보안 레드티밍 가이드』를 발간했고 2026-01-22부터 「인공지능기본법」이 시행 중이다. 그러나 이는 기업·개발자의 자체 시스템 구축·점검용 기술 매뉴얼이며 일반 이용자 대상 서드파티 중개 사이트 경보가 아니다.
  4. **금융보안원(fsec.or.kr):** 『금융분야 인공지능 보안 안내서』, 『프런티어 AI 보안 위협 금융분야 대응 요령』(2026.7.2., 금융위 공동), '금융분야 AI 에이전트 보안 평가기준'을 수립해 금융권 내부망의 SaaS 망분리 예외 시 API 관리 통제(외부 키 스토어 프록시 XKS Proxy 등)를 다루고 있으나, 일반인 대상의 사설 API 중개 플랫폼 경보는 없다.
  5. **공정거래위원회(ftc.go.kr):** 'AI 워싱(AI-Washing, 허위·과장 광고)' 방지를 위한 「인공지능 관련 표시·광고 가이드라인」 정비 및 가상인물 딥페이크 광고 규제를 추진 중이나, AI API 중개 사이트에 대한 피해주의보나 불공정약관 시정명령은 없다.
  6. **경찰청(police.go.kr) 사이버수사국:** 생성형 AI 악용 피싱, 딥페이크/딥보이스 사칭 사기, SNS를 통한 가상자산 거래소/클라우드 API 키 대여 사기 단속을 진행 중이나, AI 중개 사이트 자체를 겨냥한 수사 경보는 없다.
  7. **해외 안보기관(호주 ACSC, 캐나다 CCCS, 유럽 ENISA):** 호주 ACSC(cyber.gov.au, *Secure adoption of agentic AI systems*)와 캐나다 CCCS(cyber.gc.ca, *Managing AI token consumption for operational resilience*), 유럽 ENISA(EUVD LiteLLM 오픈소스 취약점) 등 주요국 기관도 기업 내부 토큰 통제와 게이트웨이 구축을 권고할 뿐 소비자/개인 대상 사설 AI 중개 사이트 경보는 없다.
  8. **대한민국 법원 판결문(glaw.scourt.go.kr):** API 서버 무단 크롤링 관련 판결(대법원 2021도1533 판결 등)은 있으나, 생성형 AI API 키 탈취 또는 제3자 AI 중개(릴레이) 플랫폼 관련 형사/민사 판례는 현재까지 단 1건도 등재되어 있지 않다.
  따라서 본문 제10항 비고의 "중개 사이트를 직접 겨냥한 국내 경보는 찾지 못했습니다"라는 서술은 2026년 10월 25일 기준으로도 완벽하게 사실에 부합한다.

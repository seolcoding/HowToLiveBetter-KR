# 제5절 intro/tail 독립 검토

9개 intro 고유구간과 tail 전체 교체를 승인했다. 원본·가상 결과 SHA, 고유성, 최신45 map 바인딩을 확인했다. 조건을 붙인 주제 안내가 최신 본문 범위와 맞는다.

기존14개 과제 중 SPIVA 한국 대형주 액티브 펀드 표의 존재만 확인 범위로 갱신했다. 나머지13개 미확인 주제와 개별 본문 제한은 남긴다. 상태 배너·DOI 주석·번호를 보존한다. URL/실제 통계 확인과 다른 미확인 주제를 혼동하지 않는다.

새 HTTP가 아닌 기존 직접읽기 근거를 재사용했다. 통합·전체45항·정식KR-FIT 승인이 아니다.

공개 본문은 34절·667항목이다. 원문 665항목에 한국 전용 4항목을 더하고 2항목을 제외한 구성이다. 이번 출판 품질 재검토는 진행 중이며 새 작업은 아직 배포되지 않았다. 이 감사는 독자 안내만 수정했고, 개별 절·윤문 결과·사실 감사·과거 목표 문서·목차 상태표는 변경하지 않았다.

## 지시와 생성 흐름

AGENTS.md, CLAUDE.md, KR-GUIDE.md, `kr-harness/goals/2026-10-10-gate-ebook.md`, 현재 `2026-10-publication-quality.progress.md`, 출판 CONTRACT와 작업 제약을 확인했다. 과거 목표 문서 2단계는 비공식 현지화판·원문 우선 고지와 원본 링크, TODO 보존을 요구한다. 따라서 해당 고지와 미확인 표시를 유지했다. 새 재검토는 원문 수치 복제를 넘어 연구 대상·분모·조건·현행 권고를 실제 출처에 맞게 바로잡으므로 ‘의학 수치는 원문 그대로’라는 안내는 맞지 않는다.

공용 `lib.mjs`의 NOTICE/frontFacts는 HTML·EPUB·PDF 머리말에서 사용한다. HTML은 `html.mjs`를 통해 웹 리더와 오프라인 파일에 들어간다. PDF 표지는 `template.typ`에 별도 안내가 있고, 머리말은 `pdf.mjs`에서 만든다. README 표의 ✅ 절만 수록하며 실제 빌드는 현재 본문 해시의 적합성 게이트를 재실행한다. TODO는 cleanChapter에서 지우지 않고 본문·절 끝 목록에 남기며 빌드에서 집계한다.

## FM-W01 후속 — 항목 수 비교 표시

독립 검토의 warn1을 반영했다. 한국어판 항목은 원문 항목의 부분집합이 아니므로 `frontFacts.progress/entryLine`과 HTML 진행 영역에서 항목 진행률·분수 표기를 없앴다. ‘한국어판 공개 항목667개 · 원문 전체665개’처럼 두 수를 별도로 표시한다. 수는 기존 파서의 실제 한국어 공개 항목 수와 중국어 전체 항목 수를 그대로 사용한다. 특정 추가·제외 수를 코드에 고정하지 않는다. 절 진행 막대와 미공개 절 안내는 유지한다.

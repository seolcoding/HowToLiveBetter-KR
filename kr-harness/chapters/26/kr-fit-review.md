### 26-2. 온라인으로 팔면 통신판매업 신고를 하세요. 부가통신사업에 해당하면 자본금 기준도 확인하세요
- 판정: 적합
- 새 문장 "이 안내 페이지는 개정 전 조문 번호인 "법 제22조제4항제1호"를 그대로 싣고 있습니다." → 중앙전파관리소 안내 페이지 원문: "법 제22조제4항제1호에서 "대통령령으로 정하는 기준에 해당하는 소규모 부가통신사업"이란 인터넷을 이용하여 부가통신역무를 제공하는 자본금 1억원 이하인 부가통신사업자를 말한다." 맞는다.
- 새 문장 "현행 시행령 제30조 제1항은 "법 제22조제5항제1호"로 적습니다." → DRF 시행령(시행 20261001) 제30조 제1항 원문: "법 제22조제5항제1호에서 "대통령령으로 정하는 기준에 해당하는 소규모 부가통신사업"이란 인터넷을 이용하여 부가통신역무를 제공하는 자본금 1억원 이하인 부가통신사업자를 말한다." 맞는다. 제2항의 "1개월 이내" 신고도 이득 칸과 맞는다.
- 날짜만 바뀐 "찾지 못했습니다(2026-10-22)" → 같은 안내 페이지에 "자사몰"·"쇼핑몰"이 나오지 않음을 WebFetch로 확인했다. 전자상거래 유형 설명 "온라인상의 상거래 서비스"도 원문과 같다.
- 근거: 위 시행령 DRF 주소의 제30조, 중앙전파관리소 안내 페이지.

### 26-3. 일반 인터넷 영상 서비스와 방송사업을 구분하세요. 유료 비디오물은 법정 예외를 확인하고 공급 전 등급분류를 받으세요
- 판정: 적합
- 새 문장 "서울남부지방법원은 유료로 전송한 사이트 업로드 동영상을 비디오물로 봤습니다(2019노2493)." → 판결 원문: "이 사건 사이트에 업로드된 음란동영상은 디지털 매체에 담긴 저작물로서 … ‘비디오물’에 해당한다고 보아야 하고, 대가를 지급하고 이루어지는 정보통신망을 이용한 전송행위는 위 법률이 정한 ‘유통’의 범위에 들어간다고 봄이 역시 타당하다." 판결에서 "유료"는 비디오물 해당성이 아니라 '유통' 판단에 붙는다. 본문 문장은 이 둘을 한 문장에 묶었지만 사실관계(웹하드 업로드 동영상, 유료 전송)와 결론이 원문과 어긋나지 않는다. 판결 본문에 "실시간"은 나오지 않는다. 본문 TODO 서술("업로드 파일만 다뤘다")과 맞는다.
- 새 문장 "영상물등급위원회 안내도 비디오물 예로 DVD·블루레이와 VOD·IPTV·OTT 공급 영상만 듭니다." → 안내 원문: "DVD, 블루레이 등의 매체와 VOD, IPTV, OTT 서비스에 공급되는 영상 등이 포함됩니다." 페이지에 "실시간"은 없다. 원문이 "등"으로 열어 둔 목록을 본문이 "만 듭니다"로 적었다. "든 예시가 그것뿐"이라는 뜻으로 읽히고 결론을 단정하지 않으므로 지적하지 않는다.
- 새 문장 "실시간 방송을 직접 다룬 판결도 찾지 못했습니다(국가법령정보센터 판례 검색, 2026-10-22)." → 오늘 DRF 판례 본문검색 두 건을 직접 다시 돌렸고 결과에 실시간 방송 판결은 없었다(오늘 응답은 totalCnt 0. 조사 기록은 무관 사건 3건·4건이라 적었으나 어느 쪽이든 "찾지 못했다"와 맞는다).
- 출처 칸에 추가된 2019노2493 DRF 링크와 영등위 안내 URL은 위에서 직접 열렸다.
- 근거: 위 판례 DRF 주소, 영상물등급위원회 안내 페이지, DRF 판례 검색.

### TODO 목록과 상태 줄
- 판정: 적합
- 상태 줄 "TODO 2건"은 TODO 목록 2줄과 맞는다. 원문 장문 대응 TODO는 제11항에 기간통신·부가통신 구분 문장을 넣고 지웠다. 「준비 중」「다룰 예정」 같은 표시는 없다.
- 남은 TODO 2건(자사몰의 부가통신역무 해당 여부, 실시간 라이브의 비디오물 해당 여부)은 본문이 결론을 단정하지 않는다. 제2항은 "어느 쪽이든 자본금이 1억 원 이하면 부가통신사업 신고는 하지 않아도 됩니다"로, 제3항은 등급분류 규칙을 유료 다시보기 영상에만 적용해 판정에 영향이 없다.

## 미확인

- 자기 상품만 파는 쇼핑몰이 「전기통신사업법」상 부가통신역무에 해당하는지(본문 TODO 1). 중앙전파관리소 안내에 자사몰 언급이 없다는 것만 확인했다.
- 인터넷 실시간 라이브 방송이 「영화비디오법」상 비디오물인지(본문 TODO 2). 실시간 방송을 다룬 판결·법령해석을 찾지 못했다.
- 제11항 비고의 장관 고시(기간통신역무에서 빼는 전기통신서비스)의 구체 목록. 본문은 단서가 있다는 사실만 적는다.
- 제6조 제1항 단서의 "대통령령으로 정하는 바"(부수적 기간통신역무 신고 요건). 시행령 해당 조문은 열지 않았다. 본문은 법률 단서 문장만 옮기고 세부 요건을 단정하지 않는다.
- 개정 「전자금융거래법」 제30조 제3항의 대통령령 금액, 결제 정보만 넘기는 업무의 2026-12-17 이후 지위(직전 검토에서 이어받은 미확인. 본문은 단정하지 않는다).
- 제1·4~10항과 바뀌지 않은 문장은 이번에 다시 열지 않았고 직전 검토의 직접 확인을 이어받았다.

# 제1절 한국 실정 적합성 검토

검토일: 2026-10-23 · 검토 대상: book-kr/01-너무-일찍-죽지-않기.md (항목 42개) · 직전 검토 warn 2건(제14항, 제38항) 수정 뒤 재검토

이번 재검토는 직전 검토가 warn으로 지적한 두 곳(제14항 비용 칸의 부산광역시의료원 약제비 문장, 제38항 비고와 출처 칸의 명단 운영 주체 표현)만 직전 검토의 원문 인용·수정안과 대조했다. 웹은 다시 열지 않았다. 두 곳의 근거 URL과 확인 문장은 직전 검토 것을 이어받는다. 나머지 항목은 직전 판정을 그대로 따른다. `kr-fit.mjs 01` 결과는 block 0 · warn 0이다. 시작·종료 `kr-fit.mjs 01 --hash` 값은 같았다. git 상태를 바꾸는 명령은 쓰지 않았다.

### 1-14. B형간염 항원·항체 검사를 받고, 항체가 없으면 백신을 맞으세요
- 판정: 적합(직전 warn 해소)
- 확인: 직전 문제 문장 「병원 가격은 이와 다릅니다. 공공병원인 부산광역시의료원이 공개한 성인용 백신 약제비는 한 번에 23,000원입니다.」가 「병원에서 맞으면 값이 다릅니다. 공공병원인 부산광역시의료원이 공개한 성인용 B형간염 백신 약값(약제비)은 한 번에 23,000원입니다. 이 값은 약값만이라 진찰료 같은 비용이 더 붙을 수 있으니 병원에 물어보세요.」로 바뀌었다. 직전 수정안과 글자까지 같다. 백신명이 들어갔고, 약값만이라는 범위와 진찰료가 더 붙을 수 있다는 점이 밝혀져 보건소 접종비와 섞여 읽히지 않는다. 출처 칸은 「부산광역시의료원 비급여항목별진료비 안내(약제)」로 약제 탭임이 드러난다.
- 근거: 직전 검토에서 확인한 https://www.busanmc.or.kr/busanmc/index.php?pCode=nonpayitems&mode=list&CgCode=3 (「유박스 비 (성인용) 20MCG PFS 1ML EUV20 23,000 B형간염」) · https://www.sejong.go.kr/bbs/R2002/view.do?nttId=B000000152770Xy0eM2p (「B형간염 (만 11세 이상): 7,400원」). 이번에는 다시 열지 않음.

### 1-38. 남성 간 성관계로 감염 위험이 큰 사람은 노출 전 예방약(PrEP)을 의사에게 물어보세요. 제때 먹으면 감염이 70% 넘게 줄어듭니다
- 판정: 적합(직전 warn 해소)
- 확인: 비고의 직전 문제 문장 「광주 광산구 보건소 공지는 참여 의료기관 명단으로 한국에이즈퇴치연맹의 구글 사이트 페이지를 안내합니다.」가 「광주 광산구 보건소 공지는 참여 의료기관 명단으로 구글 사이트 페이지 하나를 안내합니다(주소는 출처 칸). 이 페이지에는 운영 주체가 적혀 있지 않습니다. 2026-09-10에 마지막으로 고쳐졌고, 시도별로 병원 이름이 나옵니다. 한국에이즈퇴치연맹 홈페이지에도 처방 병원 목록이 있지만, 그 목록에는 지원사업과 무관하다고 적혀 있습니다. 명단이 바뀔 수 있으니 관할 보건소에도 물어보세요.」로 바뀌었다. 직전 수정안과 같다. 출처 칸도 「「PrEP 지원사업 참여 의료기관」(최종 업데이트 2026.09.10., 광주 광산구보건소 공지가 안내한 링크, 운영 주체 표기 없음) https://sites.google.com/ishap.org/list/hospital」로 수정안대로 고쳐졌다. 운영 주체 단정이 없어졌고, 두 목록을 같은 단체의 것으로 읽게 하는 표현도 사라졌다. 세종시 교차 확인 출처는 선택 사항이라 넣지 않은 것은 문제 아니다.
- 근거: 직전 검토에서 확인한 https://www.gwangsan.go.kr/health/boardView.do?pageId=health171&boardId=BNEWS&seq=1770877 (「참여 의료기관 명단(https://sites.google.com/ishap.org/list/hospital)」) · https://sites.google.com/ishap.org/list/hospital (「최종 업데이트 2026.09.10.」) · https://www.ishap.org/content/prevention_05 (「※이 페이지에 기재된 처방 가능 병원 목록은 질병관리청 PrEP 지원사업과는 무관합니다.」). 이번에는 다시 열지 않음.

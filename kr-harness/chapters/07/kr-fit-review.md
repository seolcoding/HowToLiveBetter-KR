# 제7절 한국 실정 적합성 검토

서른두 번째 검토다. 직전(서른한 번째) 검토의 제17항 새 지적 두 개를 오케스트레이터가 수정안 문구 그대로 반영했다. 비고의 쪽방 문장과 TODO 제17항 줄의 임대료 조사 문장이다. 두 문장이 직전 검토에서 대조한 원문 범위 안인지, 50자 이내인지만 확인했다(원문은 다시 열지 않음). 나머지 항목은 직전 판정을 잇는다.

검증 방법:
- `kr-fit.mjs 07` 결과는 block 0·warn 0이다.
- `kr-fit.mjs 07 --hash`는 시작·종료 모두 3012e4c0…이다. 직전 값(73f9b3d0…)과 다른 것은 위 두 문장 반영 때문이다.
- `git diff`(HEAD 대비)에서 바뀐 것은 제17항 출처·비고 두 줄과 TODO 제17항 줄뿐이다. 50차 추가분 전체(직전 검토에서 대조함)에 이번 두 문장 수정이 겹친 결과다.

- 이번 반영 문장 대조(직전 검토의 원문 기록 기준, 다시 열지 않음):
  - 비고 「쪽방(5개 도시)은 보증금 없는 월세가 평균 20만원 정도였습니다.」(공백 포함 37자) → 직전 검토가 적은 원문 「쪽방 거주자는 … 5개 광역시」, 「보증금액이 없는 월세의 경우, … 쪽방 거주자는 평균 20만원 정도」와 맞는다. 「5개 도시」는 5개 광역시를 풀어 쓴 것이고, 조건(보증금 없는 월세)도 들어가 범위 안이다. 앞 문장의 고시원 「6개 도시」와도 구분된다.
  - TODO 「임대료 조사는 관악구 한 곳과 주택금융공사 2019년 고시원·쪽방 조사만 봤습니다.」(46자) → 출처 칸의 조우리·김부열(2024, 관악구)과 홍희정(2021, 주택금융공사 2019년 조사)과 맞는다. 「실측」 대신 「조사」라 설문 자료와도 어긋나지 않는다.
  - 50차 추가분의 나머지 문장(주택금융공사 고시원 두 문장, 삼겹살 비교 네 문장)은 바뀌지 않았다. 직전 검토에서 숫자 모두 원문과 맞았다.
- 남은 것(직전과 같음): 단기숙박·직접 요리 절감 비율의 한국 공공 자료 없음(정직한 TODO). 기존 50자 초과 문장(56자 숙박 월세 문장, 날짜 줄·시애틀·푸드뱅크·전남광주 문장).

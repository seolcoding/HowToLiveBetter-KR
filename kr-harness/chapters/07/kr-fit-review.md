스물네 번째 검토다. 직전(스물세 번째) 검토 제17항 수정안 두 개가 본문에 반영됐다. 이 두 문장만 직전 검토 때 대조한 원문(인권위·한국도시연구소 2018 보고서 인쇄 31~34쪽)과 다시 맞춰 봤다. 나머지 항목은 직전 판정을 잇는다.

검증 방법:
- `kr-fit.mjs 07` 결과는 block 0·warn 0이다.
- `kr-fit.mjs 07 --hash`는 시작·종료 모두 5cd57eb1…이다. 직전 값(da6d59dd…)과 다른 것은 위 두 문장 변경 때문이다. `git diff --word-diff`로 본 변경 내용은 직전 검토가 대조한 40차 반영분과 두 문장뿐이다.
- 바뀐 문장 길이는 node로 셌다(공백·괄호 포함). 첫 문장 56자, 둘째 문장 30자다.

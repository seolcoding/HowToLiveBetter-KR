# 제7절 한국 실정 적합성 검토
검토일: 2026-10-10 · 검토 대상: kr-harness/runs/R07a-07-styleB/7-refined.md (항목 22개)

첫 독립 내용 검토다. 한국어 22항 전체를 다시 읽고 중국어 원문, 1-analysis.md, 2-research.md와 대조했다. 원문 중국 금액·지급기간을 환율로 옮긴 부분은 없다. DOI 10.1037/a0035923과 근거등급은 보존됐다. 같은 절 앵커의 실제 대상과 다른 절 표제를 확인했다.

시작·종료 kr-fit --check는 모두 block 0, warn 0이었다. 시작·종료 --hash도 같았다. 아래 warn은 내용 검토의 보강 권고이며 기계 검사 결과와 다르다. 정직하게 남긴 TODO 9묶음은 10항에 걸쳐 있다. 미확인 조건을 지급 약속으로 바꾸지 않은 경우는 block으로 세지 않았다.

## 현행본과 직접 열람

인용된 DRF XML 32개와 금액 첨부 PDF/HWPX 3개를 직접 받았다. 법령은 법령명·공포일·시행일과 현행 검색 결과를 대조했다. `target=eflaw`, 실제 MST와 efYd로 확인했다. 최고이자율 대통령령은 본문의 target=law 링크도 열고 현행 검색에서 MST=230727, 시행일 20210707을 확인했다. 상법은 검색 결과 3쪽에서 현행 MST=273629, 시행일 20260910을 찾았다. 공공주택 특별법은 현행 20260908과 시행예정 20270309가 같은 MST=289289를 쓰므로 날짜를 구분했다.

고용보험법 부칙 법률 제21473호는 본칙 2028-01-01, 제10조 등 2027-01-01, 제75~77조 2026-09-18 시행을 구분한다. 현행 20260918 본문 제40·46·48조로 구직급여를 판단했다. 근로기준법의 2026-12월·2027년 시행예정본도 사용하지 않았다. 국민연금법의 2027·2028년 예정 개정과 상법의 2027년 예정 조항을 현행 조언으로 옮기지 않았다. 긴급지원 고시 제2025-210호는 발령일 시행이지만 개정금액은 부칙상 2026-01-01 지급분부터 적용된다.

고용24, 노동포털, 129, NHIS static 안내 2개는 실제 내용이 열렸다. 대한법률구조공단 https://www.klac.or.kr/ 는 프록시 터널 502로 열리지 않았다. 일부 law.go.kr 재열람은 일시적 403이었지만 재시도로 확인했다. 법률구조의 법적 범위는 별도 법령 원문으로 확인했다. 열리지 않은 공단의 유형별 경제기준은 확인했다고 쓰지 않았다.

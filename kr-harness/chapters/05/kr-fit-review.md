## 비교 문맥 warn·참조·미확인
- 기계 warn 13건은 직전과 같은 중국 비교 문맥(KF-CN-STD 11건, KF-SOC 2건)이다. 이번 수정과 무관해 새로 판정하지 않았고 block으로 올리지 않는다.
- 이번 수정으로 새 참조 표기는 없다. 제10항 비고의 「제9항(아이 결제 취소)」와 「제8절(법적 말썽에 휘말리지 않기)」는 직전과 같다.
- 본문 TODO는 3건(제8·10·18항)이고 상태 줄 「TODO 3건」과 맞는다. 끝 TODO 목록 3줄도 본문 비고와 내용이 맞는다. 제10항 TODO 줄의 「중고거래 사기는 법무부 카드뉴스(2021-05-31), 게임 아이템 사기는 … 게임사기 예방수칙(청소년 한정 아님)으로 확인」은 위 원문 대조 결과와 같다.
- 미확인(본문이 단정하지 않아 판정 영향 없음):
  1. 제8항: 한 사람이 라이브 방송 후원에 쓰는 돈의 공식 통계.
  2. 제10항: 친구·교사 사칭, 팬클럽 이벤트, 후원 환불 수법을 청소년 대상으로 정리한 경찰청·금감원 공식 자료.
  3. 제18항: 한국 공모펀드 전체의 평균 총보수(운용보수 포함) 공식 통계. FreeSIS 「유형평균보수및비용」 표 값은 읽지 못했다.
  4. 제42항: 민간 보험회사가 전화 가입 만 65세 이상에게 45일 청약철회를 지금도 적용하는지(직전과 같음, 본문이 주장하지 않음).
  5. 제5항: 「온라인복권 = 로또6/45」 대응 문구의 1차 출처(직전과 같음).
  6. 제10항: 경찰청 「사이버캅」 앱이 지금도 배포·운영되는지. 경찰청 현행 수칙 페이지 두 곳이 「사이버캅」을 안내하는 것은 확인했으나 앱 배포 현황 1차 자료는 열지 못했다. 본문은 앱 설치를 권하지 않고 수칙 문장만 전한다.

## 요약
- block 0건, warn 0건, 삭제 권고 0건. 적합 45항목.

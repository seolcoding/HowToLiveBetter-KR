## 참조 대상 대조

같은 절 참조는 제1·3·4·5·6·7·12·13·18·19·20·21·29·30·38항의 실제 제목·본문과 하나씩 대조했다. 앵커어가 가리키는 권고는 모두 맞는다. 다른 절 여섯 곳은 제22절 제4항(전자담배 카트리지), 제24절(병원 이용), 제1절(너무 일찍 죽지 않기), 제6절 제26항(아침 식사·16:8), 제3절 제11항(10분 자기), 제3절 제2항(기상 시간)이다. 실제 공개 대상 제목·본문과 README 표는 직전 리뷰에서 확인, 해당 참조 문장 변경 없음. 제24절 제12항은 임플란트 비용·견적을, 제1절은 낙상·근력 운동을 다룬다. 두 파일이 빈 자리표시였다는 직전 기록의 시점 설명을 현재 사실로 재사용하지 않았다.

도입부는 「괄호 안은 항목 번호입니다」라고 밝힌 주제별 목차이며 각 번호 바로 앞에 해당 제목의 짧은 내용이 있다. 42개 번호와 주제를 모두 대조했고 오지정은 없다. 직전 리뷰가 명시적으로 허용한 `주제(제M항)` 탐색 색인을 그대로 인정한다. KR-GUIDE의 앵커 목적(숫자만으로 모호하게 지시하지 않기)을 인접 주제어가 충족한다. 실제 항목 내 참조는 `제M항(앵커어)`를 쓴다. TODO 목록 항 번호는 내부 식별자다. 「담배사업법」 제12조 제2항·제4항 등은 법 조문 번호여서 책 항목 참조로 바꾸지 않는다. 공개 여부 안내는 상태 배너를 제외한 독자 본문에 없다.

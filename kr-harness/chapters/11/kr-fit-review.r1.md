# 제11절 한국 실정 적합성 검토
검토일: 2026-10-10 · 검토 대상: kr-harness/runs/R11a-11-styleB/7-refined.md (항목 19개)

AGENTS.md, CLAUDE.md의 한국어판 규칙, KR-GUIDE.md, 검토 에이전트·스킬, 목표 문서의 설계 원칙·금지, 한국 1차 출처 목록, 원문 19항, 1-analysis.md와 2-research.md를 읽었다. 본문과 조사 기록은 수정하지 않았다. 기계 검사는 block 0·warn 0이다. 시작·종료 해시는 동일하다.

한국 법령 18건은 조사 기록의 MST와 실제 기본 시행일을 지정한 국가법령정보센터 DRF XML을 독립적으로 직접 받았다. 조회 형식은 `https://www.law.go.kr/DRF/lawService.do?OC=test&target=eflaw&MST=<MST>&efYd=<시행일>&type=XML`이다. 확인한 MST/efYd는 290189/20261002, 290185/20261002, 290001/20261002, 265811/20251023, 283673/20260828, 286627/20260903, 283839/20260911, 277201/20260528, 280043/20260603, 290247/20261002, 283335/20260811, 277197/20251001, 277359/20251001, 282791/20260721, 282793/20260721, 285185/20261001, 290505/20261002, 285279/20261008이다. 각 기본정보 시행일이 요청값과 맞고, 반환본 조문시행일자에 검토일 이후 날짜가 없음을 확인했다. 시행예정 최신본을 현행으로 사용하지 않았다. 행정규칙 2건과 판례 8건도 LSW 원문을 직접 열었다. 아래 URL과 인용은 이 직접 열람을 가리킨다.

## 항목별 판정

### 11-1. 작업 전에 피해와 권한부터 확인하세요. 수사받으면 형사 변호사를 찾으세요
- 판정: 수정 권장(warn)
- 문제: “검사의 구속기간은 인치받은 뒤 10일입니다.” → 일반 기간은 맞지만 체포·구인된 날부터 기산하는 제203조의2를 함께 설명하면 체포기간을 별도로 더하는 오독을 줄인다.
- 수정안: “체포·구인된 경우 그날부터 구속기간을 계산합니다.”를 보강하고 출처에 제203조의2를 추가한다. 수사 단계·영장심사 불산입·변호사 선임비 구분은 유지한다.
- 근거: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=290189 제200조의2 제5항 “체포한 때부터 48시간이내”; 제202·203조 각 10일; 제205조 “10일을 초과하지 아니하는 범위…1차”; 제203조의2 “체포 또는 구인한 날부터 기산”; 제243조의2 “정당한 사유가 없는 한…참여”.

### 11-2. 승인받지 않은 게임 핵·사설 서버를 만들거나 배포하지 마세요
- 판정: 수정 권장(warn)
- 문제: “앱 개조판의 한국 판례는 아래 TODO에 남겼습니다.” → 정직한 미확인이다. 현재 문장은 게임 법정요건과 앱 개조를 구분하므로 block은 아니다.
- 수정안: 앱 개조판 판매 사건을 직접 확인하기 전에는 특정 형량·사건을 추가하지 않는다.
- 근거: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=265811 제32조 제1항 제8호 “정상적인 운영을 방해할 목적으로…배포하거나 배포할 목적으로 제작”; 제46조 1년/1천만원, 제44조 5년/5천만원. https://www.law.go.kr/LSW/precInfoP.do?precSeq=214311 2019도2862는 화면 인식 자동조준의 악성프로그램 해당성을 부정한 사건으로, 게임산업법 전체 합법 판결이 아니다.

### 11-3. 재판매용 부정 예매와 순위 조작을 자동화하지 마세요
- 판정: 적합
- 문제: 없음. 재판매 목적, 공정한 구매 과정 우회·방해, 판매자 동의 없는 상습·영업 판매를 구분했다.
- 수정안: 없음.
- 근거: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=283673 제4조의2 “재판매를 목적으로”, “상습 또는 영업으로…자신이 구입한 가격을 넘는 금액”; 제4조의4 “판매금액의 50배 이하”; 제41조 1년/1천만원. https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=286627 제6조의2·제49조의2 대응 규정. https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=290185 제314조 장애·업무방해 5년/1천500만원. https://www.law.go.kr/LSW/precInfoP.do?precSeq=225803 일반 사용자와 같은 경로로 자동 게시하며 실제 장애 증거가 없는 사건의 악성프로그램 무죄. 모든 자동화를 처벌한다고 쓰지 않았다.

### 11-4. 크롤링 전에 접근권한과 데이터 이용권부터 확인하세요

### 11-5. 불법 도박·사기용 개발과 결제 계정 대여를 받지 마세요

### 11-6. 퇴사할 때 권한을 넘기세요. 데이터 삭제와 백도어로 보복하지 마세요

- 문제: 없음. 예전 비밀번호의 작동과 적법한 권한, 임금 청구를 구분했다.
- 수정안: 없음.
- 근거: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=290001 제48·49·71조 침입·인증 우회 장치·타인 정보 훼손 5년/5천만원. https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=290185 제314·366조 장애·전자기록 효용 침해. https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=285279 제36조 “14일 이내”, “당사자 사이의 합의에 의하여 기일을 연장”. https://www.law.go.kr/LSW/precInfoP.do?precSeq=216531 권한 설정 주체는 서비스제공자. 퇴사 사건 판례라고 소개하지 않았다.

- 수정안: 없음.

### 11-8. 허락 없이 남의 기기에서 프로그램을 돌리지 마세요

- 근거: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=290001 제48조 침입, 악성프로그램, “정보통신망의 안정적 운영을 방해할 목적으로” 장애 발생; 제70조의2 7년/7천만원, 제71조 5년/5천만원. https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=290185 제314조 정보처리 장애 업무방해. 기기 수 기준이나 중국 직업금지를 옮기지 않았다.

### 11-9. 서면 승인 없이 남의 시스템을 보안 점검하지 마세요

### 11-10. 취약점 공개는 제조사와 조율하세요. 공격 도구 배포는 따로 따지세요

- 수정안: 프로그램 약정 원문을 확보한 뒤 적용 프로그램과 확인일을 명시한다. 확인 전에는 90일·포상액 같은 숫자를 추가하지 않는다.

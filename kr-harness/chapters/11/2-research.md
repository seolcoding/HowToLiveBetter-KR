# 제11절 조사 기록 — 현행 한국 대응

확인일: **2026-10-10**. 기존 조사 메모를 이번 실행에서 다시 확인했다. 아래의 ‘확인’은 이번 실행에서 직접 받은 원문에 한정한다. 기존 메모에 있더라도 이번에 본문을 받지 못한 기관 자료·약관은 확인 완료로 취급하지 않았다.

## 조회 방법과 시행일

국가법령정보센터 공개 DRF(`OC=test`)의 `target=eflaw` 원문 XML을 사용했다. 조회 형식은 `https://www.law.go.kr/DRF/lawService.do?OC=test&target=eflaw&MST=<아래 lsiSeq>&efYd=<아래 시행일 YYYYMMDD>&type=XML`이다. 각 반환 본문의 기본정보(공포번호·공포일자·시행일자)와 조문단위를 대조했다. 법명 검색은 `lawSearch.do?OC=test&target=eflaw&type=XML&query=...`을 썼다. 정보통신망법 검색 첫 결과는 시행예정 2027-04-01 본이었다. 이를 쓰지 않고 **290001 / 20261002** 본을 지정했다. HTTP 200이나 검색 목록만으로 조문을 확인했다고 기록하지 않았다.

아래 표의 URL은 독자용 국가법령정보센터 주소다. 원문 직접 조회에는 위 DRF 형식을 썼다. 확인한 한국 수치만 초역에 넣었으며, 원문 중국 금액·건수·형량은 전부 교체했다.
